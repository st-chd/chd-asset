# 형식: @표기|분류  (분류: short, story, template, stscript, lalib)
@{{.이름}}|short
[[채팅 변수]]의 값을 꺼냅니다. `{{getvar::이름}}`을 줄여 쓴 것이고 결과는 똑같습니다.
```text
{{.mood}}
{{getvar::mood}}
```
두 줄 모두 변수 `mood`의 값(예: `설렘`)으로 바뀝니다.
! 축약에는 영어로 된 변수 이름만 쓸 수 있습니다. 영문자로 시작하고 영문자·숫자·`_`·`-`만 됩니다. 그 밖의 이름(한글, 빈칸이 든 이름)으로 만든 변수는 축약하지 말고 `{{getvar::이름}}`으로 꺼내세요.

@{{$이름}}|short
[[전역 변수]]의 값을 꺼냅니다. `{{getglobalvar::이름}}`을 줄여 쓴 것입니다.
```text
{{$season}}
{{getglobalvar::season}}
```
두 줄 모두 전역 변수 `season`의 값(예: `겨울`)으로 바뀝니다.
이 아래의 축약은 모두 점(`.`)으로 적었습니다. 점을 달러(`$`)로 바꾸면 전역 변수에 대해 똑같은 일을 합니다.

@{{.이름 = 값}}|short
변수에 값을 **저장**합니다. `{{setvar::이름::값}}`과 같습니다. 값은 변수 안에 들어가고, 매크로를 쓴 자리에는 아무 글자도 남지 않습니다.
```text
{{.mood = 설렘}}오늘 {{char}}의 기분은 {{.mood}}.
```
```result
오늘 가나디의 기분은 설렘.
```
`=` 앞뒤의 빈칸은 있어도 없어도 됩니다.

@{{.이름++}}|short
변수를 **1 늘리고**, 늘어난 값으로 바뀝니다. `{{.이름--}}`는 1 줄이고 줄어든 값으로 바뀝니다. 변수가 없으면 0에서 시작합니다.
```text
{{.turn++}}번째 턴
```
`turn`이 4였다면 `5번째 턴`.

@{{.이름 += 값}}|short
변수에 값을 **더합니다**. 숫자면 더하기, 글자면 이어 붙이기, [[리스트]]면 항목 추가입니다(`{{addvar}}`와 같은 규칙). 더한 결과는 변수 안에 들어가고, 매크로를 쓴 자리에는 아무 글자도 남지 않습니다. 변수가 비는 것이 아닙니다.
`{{.이름 -= 값}}`은 숫자를 뺍니다. 빼는 값이 숫자가 아니면 아무 일도 하지 않습니다.
```text
{{.gold += 50}}{{.gold -= 20}}금화: {{.gold}}
```
`gold`가 100이었다면 `{{.gold += 50}}`으로 150, `{{.gold -= 20}}`으로 130이 됩니다. 두 매크로는 글자를 남기지 않으므로 보이는 것은 마지막 `{{.gold}}`뿐입니다.
```result
금화: 130
```
전역 변수는 점 대신 달러를 씁니다. `{{$gold += 10}}`은 전역 변수 `gold`에 10을 더합니다.

@{{.이름 || 기본값}}|short
변수 값이 [[참과 거짓|거짓]](빈칸·`false`·`0`·`off`)이면 **기본값**을, 참이면 변수 값을 보여 줍니다. 변수에 저장하지는 않습니다.
```text
{{char}}의 별명: {{.nickname || 없음}}
```
`nickname`을 안 정했거나 비어 있으면 `가나디의 별명: 없음`, `토끼`로 정했으면 `가나디의 별명: 토끼`.
`{{.이름 ||= 기본값}}`은 거짓일 때 기본값을 변수에 **저장까지** 하고 그 값을 보여 줍니다.

@{{.이름 ?? 기본값}}|short
`??`는 "변수가 **아직 없으면**"이라는 뜻의 기호입니다. 변수에 값을 저장한 적이 없을 때만 기본값을 보여 줍니다. `||`와 달리, 값이 `0`이나 빈칸이어도 저장한 적이 있으면 그 값을 그대로 보여 줍니다.
| `hp`의 상태 | `{{.hp || 100}}` | `{{.hp ?? 100}}` |
|---|---|---|
| 저장한 적 없음 | `100` | `100` |
| `0` | `100` | `0` |
| `50` | `50` | `50` |
`{{.이름 ??= 기본값}}`은 `??`에 `=`(저장)를 붙인 것입니다. 변수가 아직 없을 때만 기본값을 **저장**하고, 그 자리에 변수 값을 보여 줍니다. 이미 값이 있으면 저장은 하지 않고 지금 값만 보여 줍니다.
```text
체력: {{.hp ??= 100}}
```
```result
체력: 100
```
이것을 캐릭터 카드에 넣어 두면, 처음 답을 받을 때 `hp`가 100이 되고 `체력: 100`이 들어갑니다. 그 뒤로는 `hp`가 이미 있으므로, 값이 70으로 바뀌어 있으면 덮어쓰지 않고 `체력: 70`이 들어갑니다. "처음 한 번만 값을 정하기"에 씁니다(`{{setvar::hp::100}}`은 답을 받을 때마다 100으로 되돌립니다).
! 매크로만 따로 두어도 값은 글자로 남습니다. `{{.hp ??= 100}}` 한 줄만 넣으면 그 자리에 숫자가 찍히니, 값이 보여야 할 자리에 두세요.
! 기본값 자리에 넣은 매크로는 기본값이 필요할 때만 실행됩니다. `{{.x ?? {{roll::1d6}}}}`은 `x`가 있으면 주사위를 굴리지 않습니다.

@{{.이름 == 값}}|short
변수 값이 그 글자와 **똑같으면** `true`, 아니면 `false`로 바뀝니다. `{{.이름 != 값}}`은 반대로 다르면 `true`입니다. 주로 `{{if}}`의 조건 자리에 넣습니다.
```text
{{if {{.weather == 비}}}}{{char}}는 우산을 챙긴다.{{/if}}
```
`weather`가 `비`일 때만 문장이 남습니다. 글자를 한 글자도 다르지 않게 비교하므로 `비 `(뒤에 빈칸)나 `Rain`은 다르게 봅니다.

@{{.이름 > 값}}|short
변수 값을 **숫자로** 비교해 `true`/`false`로 바뀝니다. `>`(크다), `>=`(크거나 같다), `<`(작다), `<=`(작거나 같다)를 씁니다.
```text
{{if {{.affection >= 50}}}}{{char}}는 {{user}}에게 기대 온다.{{/if}}
```
`affection`이 50 이상일 때만 문장이 남습니다.
- 변수에 값을 저장한 적이 없거나 비어 있으면 **0**으로 칩니다. 그래서 `affection`이 없을 때 `{{.affection < 10}}`은 `true`입니다.
- 변수나 비교할 값이 숫자가 아니면(`많음` 등) 항상 `false`입니다.

@{{system}}|story
[[고급 서식]] 화면의 시스템 프롬프트 내용으로 바뀝니다.

@{{#if 이름}}…{{/if}}|story
이야기 문자열 칸에서 쓰는 조건입니다. `if` 앞에 반드시 `#`을 붙입니다. 그 이름의 값이 **비어 있지 않으면** 사이 글을 남기고, 비어 있으면 지웁니다.
```text
{{#if description}}{{description}}
{{/if}}{{#if personality}}{{char}}의 성격: {{personality}}
{{/if}}{{#if scenario}}상황: {{scenario}}
{{/if}}
```
캐릭터 설명은 있고 성격 요약은 비어 있고 시나리오가 `카페에서 만남`이라면:
```result
밝고 다정한 소꿉친구.
상황: 카페에서 만남
```
성격 줄은 성격 요약 칸이 비어 있어서 통째로 빠졌습니다.
- `{{else}}`도 씁니다: `{{#if scenario}}상황: {{scenario}}{{else}}상황 없음{{/if}}`
- 반대 조건은 `{{#unless 이름}}…{{/unless}}`입니다. 비어 있을 때만 남깁니다.
- 여기서는 "비어 있는지"만 봅니다. 일반 `{{if}}`와 달리 `false`나 `0`이라는 **글자**가 들어 있으면 참으로 봅니다.
**이야기 문자열 칸에서 하면 안 되는 것**
| 쓴 것 | 일어나는 일 |
|---|---|
| `{{if description}}…{{/if}}` (`#` 없음) | "Error rendering story string" 오류가 뜨고 AI 답이 생성되지 않음 |
| `{{.hp}}`, `{{$gold}}` (축약) | 같은 오류 |
| `{{getvar hp}}` (빈칸으로 칸 나누기) | 칸이 사라져 엉뚱한 값이 됨 → `{{getvar::hp}}`로 쓰기 |
| `{{#if getvar::hp}}` (조건에 변수) | 항상 거짓 |
`{{getvar::hp}}`, `{{random::a::b}}`처럼 `::`로 쓴 보통 매크로는 이야기 문자열 안에서도 그대로 바뀝니다. 변수로 조건을 걸고 싶다면 이야기 문자열이 아닌 칸(작가 노트, 캐릭터 설명 등)에서 일반 `{{if}}`를 쓰세요.
! 다른 칸에서 `{{#if}}`를 쓰면 일반 `{{if}}`에 "블록 공백을 지우지 마라"(`#`) 표시를 붙인 것으로 동작합니다. 조건으로는 똑같이 동작하지만 사이 글의 앞뒤 빈 줄이 지워지지 않습니다.

@{{wiBefore}}|story
[[월드 인포]] 항목 중 위치를 "캐릭터 정의 **전**"으로 정한 것들 가운데, 이번에 켜진 항목의 내용으로 바뀝니다. `{{loreBefore}}`도 같습니다. 이야기 문자열 칸에서만 값이 있습니다.

@{{wiAfter}}|story
월드 인포 항목 중 위치를 "캐릭터 정의 **후**"로 정한 것들 가운데, 켜진 항목의 내용으로 바뀝니다. `{{loreAfter}}`도 같습니다.

@{{anchorBefore}}|story
확장들이 "이야기 문자열 앞쪽"에 넣으려고 보낸 글을 모은 것으로 바뀝니다(예: 일부 요약·기억 확장의 내용).

@{{anchorAfter}}|story
확장들이 "이야기 문자열 뒤쪽"에 넣으려고 보낸 글을 모은 것으로 바뀝니다.

@{{description}} 외|story
이야기 문자열 칸에서는 `{{description}}`, `{{personality}}`, `{{persona}}`, `{{scenario}}`, `{{char}}`, `{{user}}`, `{{mesExamples}}`, `{{mesExamplesRaw}}`도 미리 준비된 값으로 바뀝니다. 이름은 일반 매크로와 같지만, 이 칸에서는 프롬프트를 만드는 과정에서 따로 준비한 값이 먼저 쓰입니다.
예: `{{persona}}`는 페르소나 관리 화면에서 페르소나 설명의 위치를 "이야기 문자열 / 프롬프트 관리자"가 아닌 다른 곳으로 정해 두었으면 이 칸에서는 빈칸입니다(다른 위치에 따로 들어가므로 두 번 들어가지 않게).

@{{caption}}|template
이미지 캡셔닝 확장의 메시지 템플릿 칸에서, AI가 만든 **이미지 설명**으로 바뀝니다.
```text
[{{user}}가 보낸 사진: {{caption}}]
```
```result
[챗시가 보낸 사진: 바닷가에서 웃고 있는 강아지]
```

@{{prompt}}|template
이미지 생성 확장의 채팅 메시지 템플릿 칸에서, 그림을 만들 때 쓴 **그림 프롬프트**로 바뀝니다. `{{prefixedPrompt}}`는 캐릭터별 긍정 프롬프트(`{{charPrefix}}`)까지 붙은 프롬프트입니다.

@{{summary}} (템플릿)|template
채팅 요약 확장의 "삽입 템플릿" 칸에서, 넣을 **요약문**으로 바뀝니다. 일반 `{{summary}}` 매크로와 이름이 같습니다.
```text
[지금까지의 요약: {{summary}}]
```

@{{words}}|template
채팅 요약 확장의 "요약 프롬프트" 칸에서, 설정한 **목표 단어 수**로 바뀝니다. `{{words}}단어 이내로 요약해`처럼 씁니다.

@{{labels}}|template
캐릭터 감정 표현들 확장이 AI에게 표정을 고르게 할 때 쓰는 프롬프트 칸에서, 고를 수 있는 **표정 이름 목록**으로 바뀝니다.

@{{text}}|template
벡터 저장소·데이터 저장소의 삽입 템플릿 칸에서, 검색으로 찾아온 **글 조각**으로 바뀝니다.

@{{lastChatMessage}}|template
[[Text Completion|Chat Completion]]의 "계속 넛지" 프롬프트 칸(계속 생성하기를 누를 때 덧붙는 안내문)에서, 이어 쓸 **메시지 내용**으로 바뀝니다.

@{{match}}|template
정규식 확장의 "다음으로 바꾸기" 칸에서, 찾은 글 **전체**로 바뀝니다(`$0`과 같음).
```text
정규식 찾기: /\d+원/
다음으로 바꾸기: **{{match}}**
```
`3000원`을 찾았다면 `**3000원**`으로 바뀝니다.

@{{pipe}}|stscript
**바로 앞 명령의 결과값**으로 바뀝니다([[파이프]]).
```stscript
/len 안녕하세요 |
/echo 글자 수: {{pipe}}
```
`/len`이 글자 수 `5`를 결과값으로 남기고, 그 값이 `{{pipe}}` 자리에 들어가 알림 `글자 수: 5`가 뜹니다.
! 캐릭터 설명 같은 곳에 `{{pipe}}`를 써도 AI의 답이나 다른 값이 들어가지 않습니다. 명령 안에서만 씁니다.

@{{var::이름}}|stscript
`/let`이나 `/var`로 만든 [[범위 변수]]의 값을 꺼냅니다. 범위 변수는 스크립트가 실행되는 동안만 있는 임시 변수입니다.
```stscript
/let 이름 챗시 |
/echo 안녕, {{var::이름}}
```
1. `/let 이름 챗시` — `이름`이라는 범위 변수를 만들고 `챗시`를 넣습니다.
2. `{{var::이름}}`이 `챗시`로 바뀌어 알림 `안녕, 챗시`가 뜹니다.
`{{var::bag::0}}`처럼 셋째 칸을 주면 리스트·딕셔너리의 한 칸을 꺼냅니다.
! `{{getvar::이름}}`(채팅에 저장된 변수)과는 다른 곳입니다. `/let`으로 만든 값은 `{{getvar}}`로 꺼낼 수 없습니다.

@{{timesIndex}}|stscript
`/times`로 반복할 때 **지금 몇 번째인지**로 바뀝니다. 0부터 셉니다.
```stscript
/times 3 {: /echo {{timesIndex}}번 :}
```
알림이 `0번`, `1번`, `2번` 순서로 뜹니다.

@{{arg::이름}}|stscript
[[빠른 답장]] 버튼을 다른 스크립트에서 실행할 때 **함께 넘겨준 값**을 꺼냅니다. 같은 버튼을 값만 바꿔 가며 여러 곳에서 쓸 수 있게 해 줍니다.
버튼을 이름으로 실행하는 명령은 `/run 버튼이름`이고, 줄여서 `/:버튼이름`이라고 씁니다. `/:` 뒤에 `이름=값`을 붙이면 그 값이 버튼에 넘어갑니다.
1. "인사"라는 빠른 답장 버튼을 만들고 내용을 `/echo 안녕, {{arg::who}}`로 적습니다. 버튼을 만들 때는 `who`에 들어갈 값이 아직 정해지지 않았습니다. "실행할 때 `who`라는 이름으로 넘겨받은 값을 여기에 넣겠다"는 자리만 잡아 둔 것입니다.
2. 다른 스크립트(또는 입력창)에서 `/:인사 who=끼끼`를 실행합니다. "인사" 버튼을 실행하면서 `who`라는 이름에 `끼끼`라는 값을 담아 넘겨줍니다.
3. 버튼 안의 `{{arg::who}}`가 넘겨받은 값 `끼끼`로 바뀌어 알림 `안녕, 끼끼`가 뜹니다.
`/:인사 who=도다리`로 실행하면 같은 버튼이 알림 `안녕, 도다리`를 띄웁니다.
- `/run`으로 쓸 때는 이름 있는 인자를 앞에 두어 `/run who=끼끼 인사`입니다.
- 값을 넘겨주지 않고 실행하면 `{{arg::who}}`는 빈칸입니다. 넘겨주지 않았을 때 쓸 기본값은 `/qr-arg`로 정합니다.
- 넘겨준 값은 그 버튼이 실행되는 동안만 있습니다. 채팅 변수로 저장되지 않습니다.

@{{item}} / {{index}}|lalib
LALib [[확장]]의 `/foreach`, `/map`, `/filter`, `/find` 같은 "목록을 하나씩 돌며 처리하는" 명령 안에서, **지금 처리 중인 항목**(`{{item}}`)과 그 **번호나 이름표**(`{{index}}`)로 바뀝니다.
```stscript
/foreach ["사과","배"] {: /echo {{var::index}}: {{var::item}} :}
```
알림이 `0: 사과`, `1: 배`로 뜹니다.
! `{{item}}`, `{{index}}`는 옛 방식입니다. 지금은 위처럼 `{{var::item}}`, `{{var::index}}`를 권합니다. 클로저에서 이름을 바꿔 정했다면 그 이름을 씁니다.

@{{exception}} / {{error}}|lalib
LALib의 `/try`로 실행하다 오류가 났을 때, `/catch` 안에서 **오류 메시지**로 바뀝니다.

@{{value}}|lalib

@{{$0}} {{$1}} …|lalib
LALib의 `/re-replace`(정규식으로 찾아 바꾸기)에서 `cmd`로 넘긴 클로저 안에서 쓰는 이름들입니다.
| 이름 | 뜻 |
|---|---|
| `{{$0}}` | 찾은 글 전체 |
| `{{$1}}`, `{{$2}}` … | [[정규식]]의 괄호 `( )`로 묶은 1번째, 2번째 부분 |
| `{{$:이름}}` | 이름 붙인 괄호 `(?<이름>…)` 부분 |
| `{{$index}}` | 찾은 위치(앞에서부터 몇 번째 글자인지) |
| `{{$input}}` | 찾기 대상 글 전체 |
! 새 매크로 엔진에서는 `{{$이름}}`이 [[전역 변수]] 축약이기도 해서 겹칠 수 있습니다. 특히 `{{$index}}`, `{{$input}}`은 쓰기 전에 짧게 시험해 보세요.
