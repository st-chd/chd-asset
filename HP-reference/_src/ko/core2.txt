@sys
**내레이터 메시지**(나도 캐릭터도 아닌 해설)를 채팅에 올립니다. AI에게 답을 요청하지는 않습니다. 이 메시지도 AI에게 보내는 프롬프트에 들어갑니다.
```stscript
/sys 해가 지고, 거리에 하나둘 불이 켜졌다.
```
채팅에 `System` 이름으로 해설 메시지가 올라갑니다.
```stscript
/sys at=0 이 이야기는 겨울방학이 배경이다.
```
`at=0`이라 채팅 **맨 앞**에 끼워 넣습니다.
.compact 작게(컴팩트 배치로) 표시
.name 이 메시지에만 쓸 내레이터 이름. 비우면 `/sysname`으로 정한 이름(기본 `System`)
.at 끼워 넣을 자리(메시지 번호). 비우면 맨 끝. `-1`은 마지막 메시지 바로 앞
#0 메시지 내용

@sysname

```stscript
/sysname 해설
```
이제 `/sys`로 올리는 메시지는 `해설`이라는 이름으로 보입니다.

@regenerate
**재생성** 기능입니다. 마지막 AI 답을 버리고 새로 받습니다(메시지 메뉴의 재생성 버튼과 같음).
```stscript
/regenerate await=true
```

@swipe

/swipe
/swipe direction=left
```
첫 줄은 다음 버전(오른쪽), 둘째 줄은 이전 버전(왼쪽)으로 넘깁니다.
.direction 넘길 방향
=right 다음 버전으로
=left 이전 버전으로
.await `true`면 넘기기(새로 생성하는 경우 포함)가 끝날 때까지 기다림

@go

/go 끼끼
```

#0 AI에게 줄 지시

@ask
**다른 캐릭터**에게 잠깐 물어보고 답을 받습니다. 지금 채팅에서 그 캐릭터 카드로 한 번 답을 받은 뒤, 원래 캐릭터로 돌아옵니다.
```stscript
/ask name=끼끼 가나디에 대해 어떻게 생각해?
```
1. `가나디에 대해 어떻게 생각해?`가 내 메시지로 채팅에 올라갑니다.
2. 잠깐 캐릭터가 `끼끼`로 바뀌어, 끼끼의 카드로 AI가 답을 씁니다. 그 답이 `끼끼`의 메시지로 채팅에 올라갑니다.
3. 다시 원래 캐릭터(가나디)로 돌아옵니다. 다음 대화부터는 가나디가 답합니다.
! 그룹 채팅에서는 쓸 수 없습니다.
! 답을 받는 동안 SillyTavern은 "지금 캐릭터"를 잠깐 다른 캐릭터로 바꿔 둡니다. 그 사이에 무언가가 채팅을 저장하려 하면(변수를 저장하는 매크로가 든 프롬프트, 답을 받을 때 채팅에 기록을 남기는 확장 등) 엉뚱한 캐릭터의 채팅 파일에 저장될 뻔하므로, SillyTavern이 이를 막고 **"Chat integrity check failed"**(데이터를 잃을 수 있다는 경고) 창을 띄울 수 있습니다. 이 창이 뜨면 `OVERWRITE`를 입력하지 말고 그대로 OK를 눌러 새로 고치세요. 채팅은 그대로 남아 있습니다. 이 창이 자주 뜬다면 `/ask` 대신 [[그룹 채팅]]을 쓰거나, 답만 필요하면 `/gen`을 쓰는 편이 안전합니다.
.name 대답할 캐릭터 이름 또는 아바타 키

#0 캐릭터 이름 또는 아바타 키

@send
**내 메시지**를 채팅에 올립니다. AI에게 답을 요청하지는 않습니다. 답도 받으려면 뒤에 `/trigger`를 붙입니다.
```stscript
/send 같이 산책 갈래? ||
/trigger
```
1. 내 이름으로 `같이 산책 갈래?`가 올라갑니다.
2. `/trigger`가 AI 답을 받아 옵니다. `||`는 `/send`의 결과가 `/trigger`로 넘어가지 않게 끊는 것입니다.
.compact 작게 표시
.name 보낸 사람으로 표시할 이름. 비우면 이름 없이 표시
.at 끼워 넣을 자리. 비우면 맨 끝. `-1`은 마지막 메시지 바로 앞
#0 메시지 내용

@trigger
AI에게 답을 요청합니다(보내기 버튼을 빈 입력창으로 누른 것과 같음).
```stscript
/trigger
/trigger await=true | /echo 답이 왔습니다
```
- [[그룹 채팅]]에서는 답할 캐릭터를 이름이나 번호로 고를 수 있습니다: `/trigger 끼끼`. 안 고르면 그룹 설정의 순서대로 답합니다.
- 그래서 앞 명령의 결과값이 이 자리에 자동으로 들어가면 캐릭터 이름으로 잘못 읽힐 수 있습니다. 결과값을 남기는 명령 뒤에 쓸 때는 `|` 대신 `||`로 이으세요(`||`는 결과값을 자동으로 넣지 않습니다).
.await `true`면 답이 다 올 때까지 기다림

.name 이 이름으로 보낸 메시지만 숨김

#0 지울 스와이프 번호(1부터). 비우면 지금 보고 있는 것

@echo
화면에 [[토스트|알림]]을 띄웁니다. 채팅에는 아무것도 남지 않습니다. 안내를 보여 주거나, 스크립트 중간 값을 확인할 때 씁니다. 띄운 글을 그대로 결과로 남깁니다.
```stscript
/echo 저장했습니다
/echo severity=warning title=주의 체력이 얼마 남지 않았습니다
/echo color=purple timeout=10000 보라색으로 10초 동안
```
| 줄 | 결과 |
|---|---|
| 1 | 보통(파란) 알림 `저장했습니다`가 4초 동안 |
| 2 | 경고(주황) 알림. 제목 `주의`, 본문 `체력이 얼마 남지 않았습니다` |
| 3 | 보라색 알림이 10초 동안 |
`severity=`에 쓰는 값: `info`(정보), `success`(성공, 초록), `warning`(경고), `error`(오류, 빨강).
```stscript
/echo timeout=0 extendedTimeout=0 이 알림은 직접 닫을 때까지 남아 있습니다
```
.title 알림 제목
.severity 알림 종류: `info`, `success`, `warning`, `error`
.timeout 떠 있는 시간(1000분의 1초 단위). `extendedTimeout`과 둘 다 `0`이면 직접 닫을 때까지
.extendedTimeout 마우스를 올렸다 뗀 뒤 더 떠 있는 시간(1000분의 1초 단위)
.preventDuplicates 같은 내용의 알림이 이미 떠 있으면 새로 띄우지 않음
.awaitDismissal 알림이 닫힐 때까지 다음 명령을 기다림
.cssClass 알림에 붙일 CSS 클래스 이름(직접 꾸밀 때)
.color 알림 색. 아무 CSS 색(`red`, `#FF0000`, `rgb(255,0,0)`)
.escapeHtml `false`면 글을 HTML로 그려서 `<b>굵게</b>` 같은 꾸밈이 적용됨
.onClick 알림을 누르면 실행할 [[클로저]]
#0 띄울 글

@gen
AI에게 글을 받아서 **결과로만** 남깁니다. 채팅에는 아무것도 올라가지 않습니다. 받은 글은 다음 명령에서 `{{pipe}}`로 씁니다.
지금 캐릭터 카드와 채팅 기록이 든 평소 프롬프트에 내 지시를 붙여서 보냅니다.
```stscript
/gen {{char}}의 지금 기분을 한 단어로 |
/setvar key=mood
```
AI가 `설렘` 같은 단어를 쓰면 그것이 채팅 변수 `mood`에 저장됩니다. 채팅에는 아무것도 보이지 않습니다.
.trim 마지막 문장이 중간에 끊겼으면 그 부분을 잘라 냄
.lock `on`이면 받는 동안 입력창을 잠금
.name [[지시 모드]]에서 프롬프트 안에 쓸 말하는 사람 이름. 아바타 키를 주면 그 캐릭터 이름
.length 이번에만 쓸 최대 답 길이([[토큰]])
.as AI가 누구로서 답할지. `system`(기본)은 중립 화자, `char`는 캐릭터 이름으로
#0 AI에게 줄 지시

@genraw
`/gen`처럼 AI에게 글을 받아 결과로만 남기지만, 캐릭터 카드와 채팅 기록을 **빼고** 내가 쓴 글만 보냅니다. 캐릭터와 상관없는 작업(번역, 요약, 분류 등)에 씁니다.
```stscript
/genraw 다음 문장을 영어로 번역해: 오늘 날씨 좋다 |
/echo
```
알림에 `The weather is nice today.` 같은 번역이 뜹니다.
```stscript
/genraw stop=["\n"] 아무 과일 이름 하나만
```
AI가 줄을 바꾸는 순간 멈추므로 한 줄짜리 답만 받습니다.
.lock `on`이면 받는 동안 입력창을 잠금
.instruct `off`면 [[지시 모드]] 표시를 붙이지 않고 쓴 글 그대로 보냄
.stop 이번에만 쓸 정지 글자 목록. `["\n"]` 모양
.as AI가 누구로서 답할지. `system` 또는 `char`
.system 맨 앞에 넣을 시스템 프롬프트
.prefill AI 답의 첫머리로 미리 넣어 둘 글
.length 이번에만 쓸 최대 답 길이(토큰)
.trim 답 앞에 붙은 `챗시:`, `가나디:` 같은 이름표를 잘라 냄
#0 AI에게 보낼 글

@addswipe
마지막 AI 메시지에 [[스와이프]](다른 버전)를 하나 **직접 써서** 추가합니다. 새 스와이프 번호를 결과로 남깁니다.
```stscript
/addswipe switch=true 이건 내가 직접 쓴 다른 버전이야.
```
추가하고 바로 그 버전으로 넘깁니다.
! 내 메시지나 숨긴 메시지에는 추가할 수 없습니다.
.switch 추가한 버전으로 바로 넘길지
#0 추가할 글

@stop
AI가 쓰고 있는 답을 **멈춥니다**. 실제로 멈췄으면 `true`, 쓰는 중이 아니었으면 `false`를 결과로 남깁니다.
! AI가 쓰는 동안에는 채팅 입력창으로 명령을 보낼 수 없으므로, [[빠른 답장]] 버튼이나 자동 실행 스크립트에서 씁니다.

@abort
스크립트를 **전부** 멈춥니다. 클로저 안에서 써도 바깥까지 멈춥니다.
```stscript
/input 계속할까요? (예/아니오) |
/if left={{pipe}} rule=eq right=아니오 {: /abort quiet=false 취소했습니다 :} |
/echo 계속 진행합니다
```
`아니오`를 입력하면 알림 `취소했습니다`가 뜨고 거기서 끝납니다. 그 밖의 답이면 `계속 진행합니다`.
.quiet `false`면 멈춘 이유를 알림으로 보여 줌. 기본은 조용히 멈춤
#0 멈춘 이유. `quiet=false`일 때 알림에 보임

@fuzzy
목록에서 검색어와 **비슷한** 항목을 찾아 결과로 남깁니다. 철자가 조금 틀려도 찾아 줍니다. 비슷한 게 없으면 빈 값입니다.
```stscript
/fuzzy list=["apple","banana","grape"] aple |
/echo
```
철자가 틀린 `aple`과 가장 비슷한 `apple`이 알림으로 뜹니다.
.list 후보 목록. `["a","b"]` 모양이나, 그런 목록이 든 변수 이름
.threshold 얼마나 비슷해야 하는지(0.0~1.0). 작을수록 엄격하고 `1.0`이면 아무거나 맞음
.mode 여러 개가 맞을 때 고르는 법
=first 기준을 넘는 첫 번째 항목
=best 가장 비슷한 항목
#0 찾을 글

@pass
받은 값을 **그대로** 결과로 남깁니다. 다른 이름 `/return`. 값을 다음 명령에 넘기거나, [[클로저]]의 결과를 정할 때 씁니다.
```stscript
/pass 안녕 | /echo
```
알림 `안녕`.
```stscript
/let pick {: /pass 사과 :} |
/:pick |
/echo 고른 것: {{pipe}}
```
클로저 `pick`의 결과가 `사과`가 되어 알림 `고른 것: 사과`.
! `/return`이라는 이름이지만 클로저를 그 자리에서 끝내지는 않습니다. 값을 정한 뒤 바로 끝내려면 `/return 값 | /break`.
#0 넘길 값. 글자·숫자·리스트·딕셔너리·클로저 모두 됨

@delay
다음 명령을 실행하기 전에 정한 시간만큼 **기다립니다**. 다른 이름 `/wait`, `/sleep`.
```stscript
/echo 3초 뒤에 다음 알림 |
/delay 3000 |
/echo 3초 지났습니다
```
#0 기다릴 시간(1000분의 1초 단위). `1000` = 1초

@input
글을 써 넣는 칸이 있는 [[팝업|창]]을 띄우고, 입력한 글을 결과로 남깁니다. 취소하면 빈 값입니다. 다른 이름 `/prompt`.
```stscript
/input default=챗시 placeholder="이름을 쓰세요" 당신의 이름은? |
/echo 반가워요, {{pipe}}님
```
- 창에 `당신의 이름은?`이 보이고, 입력칸에는 `챗시`가 미리 채워져 있습니다.
- 확인을 누르면 알림 `반가워요, 챗시님`.
```stscript
/input rows=5 large=on 긴 메모를 남겨 주세요
```
5줄짜리 큰 입력칸이 뜹니다.
.default 입력칸에 미리 채워 둘 글
.large 창을 세로로 크게. 입력칸 높이는 `rows=`로 따로 정함
.wide 창과 입력칸을 가로로 넓게
.okButton 확인 버튼 글자
.rows 입력칸 줄 수(여러 줄 입력)
.placeholder 입력칸이 비어 있을 때 흐리게 보이는 안내
.tooltip 입력칸에 마우스를 올리면 뜨는 설명
.onSuccess 확인(또는 Enter)으로 닫힐 때 실행할 클로저
.onCancel 취소(또는 Esc)로 닫힐 때 실행할 클로저
#0 창에 보일 질문·안내

@run
이름 붙여 둔 [[클로저]]나 [[빠른 답장]] 버튼을 실행하고, 그 결과를 결과로 남깁니다. 줄여서 `/:이름`. 다른 이름 `/call`, `/exec`.
```stscript
/run 인사
/run 내세트.인사
/run who=끼끼 인사
/:인사 who=끼끼
```
| 줄 | 하는 일 |
|---|---|
| 1 | 라벨이 `인사`인 버튼(켜져 있는 세트에서 찾음)이나 `/let`으로 만든 `인사` 클로저를 실행 |
| 2 | `내세트` 세트의 `인사` 버튼을 실행(켜져 있지 않은 세트도 됨) |
| 3 | `who=끼끼`을 넘기며 실행. 버튼 안에서 `{{arg::who}}`가 `끼끼`으로 바뀜 |
| 4 | 3과 같은 일을 줄여 쓴 것 |
! `/run`으로 값을 넘길 때는 `who=끼끼`을 이름 **앞에** 씁니다. `/run 인사 who=끼끼`이라고 쓰면 `인사 who=끼끼`이라는 이름의 버튼을 찾습니다. `/:` 줄임 쓰기에서는 이름 뒤에 씁니다.
.args 넘길 값. 실제로는 `who=끼끼`처럼 아무 이름이나 씀
#0 실행할 것: `/let`으로 만든 클로저 이름, 버튼 라벨(`세트이름.라벨`도 됨), 또는 클로저 자체

@messages
메시지 내용을 가져와 결과로 남깁니다. 다른 이름 `/message`.
```stscript
/messages 0
/messages names=on 5-7
/messages role=user {{allChatRange}}
```
| 줄 | 가져오는 것 |
|---|---|
| 1 | 0번(첫) 메시지 내용 |
| 2 | 5~7번 메시지를 `이름: 내용` 모양으로 |
| 3 | 전체 중 내가 보낸 메시지만 |
.names `on`이면 각 메시지 앞에 보낸 사람 이름을 붙임. 기본은 `off`
.hidden `off`면 `/hide`로 숨긴 메시지는 뺌
.role 이 역할의 메시지만: `user`(나), `assistant`(캐릭터), `system`(시스템)
#0 메시지 번호(0부터) 또는 `시작-끝` 범위

@setinput
채팅 **입력창**의 글을 바꿉니다(보내지는 않음). 넣은 글을 결과로 남깁니다.
```stscript
/setinput {{user}}는 고개를 끄덕였다.
```
입력창에 `챗시는 고개를 끄덕였다.`가 채워집니다. 확인하고 직접 보내면 됩니다.
#0 입력창에 넣을 글

@popup
글과 버튼이 있는 [[팝업|창]]을 띄우고, 닫을 때까지 스크립트를 멈춥니다. 간단한 HTML 꾸밈(`<b>`, `<br>` 등)도 됩니다.
```stscript
/popup okButton=확인 <b>주의</b><br>이 작업은 되돌릴 수 없습니다.
```
```stscript
/popup okButton=왼쪽 cancelButton=오른쪽 result=true 어느 길로 갈까? |
/echo 고른 것: {{pipe}}
```
`result=true`라서 누른 버튼이 숫자로 결과가 됩니다. `왼쪽`(확인 버튼)이면 `1`, `오른쪽`(취소 버튼)이면 `0`, 그냥 닫으면 빈 값.
.scroll 내용이 길면 위아래로 스크롤되게
.large 큰 창
.wide 넓은 창
.wider 더 넓은 창
.transparent 배경이 투명한 창
.okButton 확인 버튼 글자
.cancelButton 취소 버튼 글자. 이걸 써야 취소 버튼이 나타남
.result `true`면 글 대신 누른 버튼을 숫자로 돌려줌: 확인=`1`, 취소=`0`, 그냥 닫음=빈 값
.tooltip 내용에 마우스를 올리면 뜨는 설명
