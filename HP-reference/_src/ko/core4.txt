첫 줄은 채팅 변수와 전역 변수를 모두, 둘째 줄은 채팅 변수만 보여 줍니다.

@setvar
[[채팅 변수]]에 값을 **저장**하고, 저장한 값을 결과로 남깁니다. 다른 이름 `/setchatvar`.
```stscript
/setvar key=hp 100
```
지금 채팅에 `hp`라는 이름으로 `100`을 저장합니다. 이 채팅을 닫았다 열어도 남아 있고, 다른 채팅에서는 보이지 않습니다.
```stscript
/setvar key=bag ["검","방패"] |
/setvar key=bag index=0 낡은 검 |
/setvar key=stat index=hp as=number 80
```
| 줄 | 결과 |
|---|---|
| 1 | `bag`에 [[리스트]] `["검","방패"]` 저장 |
| 2 | `bag`의 0번 칸만 바꿔 `["낡은 검","방패"]` |
| 3 | `stat`의 `hp` 칸에 **숫자** 80. `stat`이 없었으면 `{"hp":80}`으로 새로 만듦 |
`index=` 없이 쓰면 변수 전체가 바뀝니다. 값 칸을 비우면 앞 명령의 결과가 저장됩니다: `/input 이름? | /setvar key=name`.
.key 변수 이름
.index 리스트·딕셔너리의 한 칸만 바꿀 때 그 위치. 리스트면 번호(0부터), 딕셔너리면 키 이름. 변수가 없으면 번호일 때 리스트, 글자일 때 딕셔너리로 새로 만듦
.as `index=`와 함께 쓸 때 넣을 값의 종류. `string`(글자, 기본), `number`(숫자), `boolean`(참거짓), `list`, `dictionary`, `null` 등

@if
두 값을 비교해서, 맞으면 한 묶음을, 아니면 다른 묶음을 실행합니다. 실행한 쪽의 결과를 결과로 남깁니다.
```stscript
/if left=hp rule=lte right=0
    else={: /echo 아직 버틸 수 있다 :}
    {: /echo 쓰러졌다! :}
```
| 부분 | 뜻 |
|---|---|
| `left=hp` | 왼쪽 값. 변수 `hp`의 값 |
| `rule=lte` | 비교 방법. "작거나 같다(≤)" |
| `right=0` | 오른쪽 값 |
| `else={: … :}` | 안 맞을 때 실행할 [[클로저]] |
| 마지막 `{: … :}` | 맞을 때 실행할 클로저. 이름 없는 인자이라 맨 뒤 |
`hp`가 0 이하면 알림 `쓰러졌다!`, 아니면 `아직 버틸 수 있다`.
`rule=`에 쓰는 값:
| 값 | 뜻 | 원래 말 |
|---|---|---|
| `eq` | 같다(안 쓰면 이것) | equal |
| `neq` | 다르다 | not equal |
| `gt` | 왼쪽이 크다 `>` | greater than |
| `gte` | 크거나 같다 `≥` | greater than or equal |
| `lt` | 왼쪽이 작다 `<` | less than |
| `lte` | 작거나 같다 `≤` | less than or equal |
| `in` | 왼쪽 글 안에 오른쪽 글이 있다(대소문자 무시) | in |
| `nin` | 왼쪽 글 안에 오른쪽 글이 없다 | not in |
| `not` | 왼쪽이 거짓이다 | not |
```stscript
/if left={{lastMessage}} rule=in right=비밀 {: /echo 비밀 이야기가 나왔다 :}
```
마지막 메시지에 `비밀`이라는 글자가 들어 있으면 알림이 뜹니다.
```stscript
/if left=hasKey {: /echo 열쇠가 있다 :}
```
`right=`를 안 쓰면 "왼쪽 값이 [[참과 거짓|참]]인가"만 봅니다. `hasKey`가 빈 값·`0`·`false`·`off`가 아니면 실행됩니다.
! `left=`와 `right=`에 쓴 값은 이 순서로 알아봅니다: 숫자 → 같은 이름의 채팅 변수 → 같은 이름의 전역 변수 → 그냥 글자. 그래서 변수 `tree`가 있으면 `left=tree`는 `tree`라는 글자가 아니라 그 변수의 값입니다.
! 예전 방식으로 실행할 명령을 따옴표로 감싸 쓸 수도 있습니다: `/if left=hp rule=gt right=0 "/echo 살아 있다"`.
.left 왼쪽 값. 숫자, 변수 이름, 글자
.right 오른쪽 값. 비우면 왼쪽이 참인지만 봄
.rule 비교 방법. 비우면 `eq`(같다)
.else 안 맞을 때 실행할 클로저 또는 따옴표로 감싼 명령
#0 맞을 때 실행할 클로저 또는 따옴표로 감싼 명령

@while
조건이 맞는 **동안** 묶음을 계속 반복합니다. 비교 방법은 `/if`와 같습니다. 매번 반복하기 전에 조건을 다시 봅니다.
```stscript
/setvar key=i 0 |
/while left=i rule=lt right=3 {:
    /incvar i |
    /echo {{getvar::i}}번째
:}
```
1. `i`가 3보다 작은 동안 반복합니다.
2. 반복할 때마다 `i`를 1 늘리고 알림을 띄웁니다.
3. 알림이 `1번째`, `2번째`, `3번째`로 뜨고, `i`가 3이 되면 멈춥니다.
! 실수로 끝나지 않는 반복이 되는 것을 막으려고 **100번**까지만 반복합니다. 더 돌려야 하면 `guard=off`를 씁니다. 카드에는 기본값이 `off`로 표시되지만, 실제로는 `guard=`를 안 쓰면 100번 제한이 걸립니다.
.left 왼쪽 값. 반복할 때마다 다시 읽음
.right 오른쪽 값
.rule 비교 방법(`/if`와 같음)
.guard `off`면 100번 제한을 없앰
#0 반복할 클로저 또는 따옴표로 감싼 명령

@times

```stscript

```
알림이 `0번`, `1번`, `2번` 순서로 뜹니다.

10씩 5번 더해서 알림 `금화: 50`.
! 100번까지만 반복합니다. 더 하려면 `guard=off`.
.guard `off`면 100번 제한을 없앰

#1 넣을 값. 비우면 읽기

@let
지금 [[범위 변수]]를 **새로 만듭니다**. 처음 값을 같이 줄 수 있고, [[클로저]]도 넣을 수 있습니다. 스크립트가 끝나면 사라집니다.
```stscript
/let name 챗시 |
/echo 안녕, {{var::name}}
```
알림 `안녕, 챗시`.
```stscript
/let greet {: /echo 반가워 :} |
/:greet
```
클로저를 `greet`에 넣어 두고 `/:greet`로 실행합니다.
! 같은 묶음 안에서 같은 이름으로 `/let`을 두 번 하면 오류입니다. 바꿀 때는 `/var`를 씁니다.
.key 변수 이름(이름 없는 인자 대신 써도 됨)
#0 변수 이름
#1 처음 값. 비우면 빈 값

@closure-serialize
[[클로저]]를 **글자로** 바꿔 결과로 남깁니다. 클로저는 원래 스크립트가 끝나면 사라지므로, 채팅 변수·전역 변수에 저장해 두고 나중에 다시 쓰려고 씁니다.
```stscript
/closure-serialize {: /echo 저장해 둔 인사 :} |
/setvar key=savedGreet
```
`/closure-deserialize`로 다시 클로저로 되돌려 씁니다.
#0 글자로 바꿀 클로저

@closure-deserialize
`/closure-serialize`로 글자로 바꿔 둔 것을 다시 [[클로저]]로 되돌립니다.
```stscript
/closure-deserialize {{getvar::savedGreet}} |
/let greet {{pipe}} |
/:greet
```
저장해 둔 클로저를 꺼내 `greet`에 넣고 실행합니다. 알림 `저장해 둔 인사`.
#0 글자로 바꿔 둔 클로저

@loader-wrap
[[클로저]]를 실행하는 동안 "작업 중" 표시(화면을 덮는 로딩 화면과 알림)를 띄우고, 끝나면 없앱니다. 클로저의 결과를 결과로 남깁니다.
```stscript
/loader-wrap message="요약하는 중..." {: /gen 지금까지 줄거리를 세 줄로 요약해 | /echo :}
```
요약을 받는 동안 화면이 덮이고 `요약하는 중...` 알림이 뜹니다. 끝나면 요약이 알림으로 뜹니다.
```stscript
/loader-wrap blocking=false message="그림 설명 중..." {: /caption :}
```
`blocking=false`라 화면은 덮지 않고 알림만 띄웁니다.
! 알림의 "중지" 버튼은 기본적으로 **AI 생성**을 멈춥니다. AI 생성이 아닌 작업을 감쌀 때는 `onStop=`에 멈추는 방법을 직접 넣으세요.
.blocking `false`면 화면을 덮지 않고 알림만
.toast 알림 모양
=none 알림 없음
=static 알림만(중지 버튼 없음)
=stoppable 중지 버튼이 있는 알림
.message 알림에 보일 글
.title 알림 제목
.slug 이 로딩 표시의 이름(코드·CSS로 구분할 때)
.stopTooltip 중지 버튼에 마우스를 올리면 뜨는 설명
.onStop 중지 버튼을 누르면 실행할 클로저. 비우면 AI 생성 중지
#0 로딩 표시를 띄운 채 실행할 클로저

@loader-show
"작업 중" 표시를 **직접 띄우고**, 나중에 닫을 때 쓸 번호(핸들)를 결과로 남깁니다. `/loader-hide`로 닫습니다. 띄우고 닫는 때를 따로 정하고 싶을 때 씁니다.
```stscript
/loader-show message="불러오는 중..." |
/setvar key=loader |
/delay 3000 |
/loader-hide handle={{getvar::loader}}
```
3초 동안 로딩 표시를 띄웠다가 닫습니다.
.blocking `false`면 화면을 덮지 않고 알림만
.toast 알림 모양
=none 알림 없음
=static 알림만
=stoppable 중지 버튼이 있는 알림
.message 알림에 보일 글
.title 알림 제목
.slug 이 로딩 표시의 이름
.stopTooltip 중지 버튼 설명
.onStop 중지 버튼을 누르면 실행할 클로저
.onHide 닫힐 때 실행할 클로저
