@space
빈칸(띄어쓰기)을 넣습니다. 숫자를 주면 그 개수만큼 넣습니다.
보통은 그냥 스페이스바를 누르면 되지만, [[슬래시 명령]]의 칸처럼 맨 앞뒤 빈칸이 자동으로 지워지는 곳에서 빈칸을 꼭 남기고 싶을 때 씁니다.
```text
[{{space}}]
[{{space::4}}]
```
```result
[ ]
[    ]
```
#0 넣을 빈칸 개수. 비우면 1개

@newline
줄바꿈(Enter를 한 번 누른 것)을 넣습니다. 숫자를 주면 그 개수만큼 넣습니다.
줄을 바꿀 수 없는 한 줄짜리 입력칸이나, 명령 안에서 줄을 나누고 싶을 때 씁니다.
```stscript
/echo 첫째 줄{{newline}}둘째 줄
```
알림 안에서 `첫째 줄`과 `둘째 줄`이 두 줄로 나뉘어 보입니다.
#0 넣을 줄바꿈 개수. 비우면 1개

@noop
아무것도 넣지 않습니다(그 자리가 [[빈 값|빈칸]]이 됩니다).
"여기는 일부러 비워 둔다"는 것을 명령에 알려야 할 때 씁니다. 예를 들어 `/stop-strings`는 값을 비워 두면 "지금 값을 알려 달라"로 알아듣기 때문에, 목록을 정말로 비우려면 빈 값을 직접 넘겨야 합니다.
```stscript
/stop-strings force=true {{noop}}
```
정지 문자열 목록을 빈 목록으로 바꿉니다.

@trim
앞뒤의 빈 줄을 지웁니다. 쓰는 방법이 두 가지입니다.
**혼자 쓸 때**: `{{trim}}`이 있던 자리와 그 바로 앞뒤의 줄바꿈이 모두 사라져 위아래 줄이 붙습니다.
```text
첫째 줄
{{trim}}
둘째 줄
```
```result
첫째 줄둘째 줄
```
**[[블록]]으로 쓸 때**: `{{trim}}`과 `{{/trim}}` 사이에 넣은 내용에서 **맨 앞과 맨 뒤**에 붙은 빈칸·빈 줄을 지웁니다. 내용 가운데의 줄바꿈은 그대로 둡니다.
```text
[{{trim}}

    이름: 가나디
    나이: 비밀

{{/trim}}]
```
```result
[이름: 가나디
나이: 비밀]
```
1. `[` 바로 뒤의 빈 줄과 `]` 바로 앞의 빈 줄이 지워져, 내용이 대괄호에 딱 붙었습니다.
2. 두 줄 사이의 줄바꿈은 내용 가운데에 있으므로 그대로 남았습니다.
3. 줄 앞의 빈칸 4개(들여쓰기)도 지워졌습니다. 블록 내용은 첫 줄 앞의 빈칸 개수만큼 모든 줄의 앞쪽 빈칸을 지우기 때문입니다(매크로 문법의 "블록 안의 공백").
카드나 프롬프트를 보기 좋게 여러 줄로 나눠 쓰면서도, AI에게는 군더더기 빈 줄 없이 보내고 싶을 때 씁니다.
#0 블록으로 쓸 때 사이에 넣는 내용

@if
조건에 따라 글을 **넣거나 빼는** 매크로입니다. "이 조건이 맞으면 이 글을 넣고, 아니면 빼라(또는 다른 글을 넣어라)"를 뜻합니다.
```text
{{if 조건}}맞을 때 넣을 글{{else}}안 맞을 때 넣을 글{{/if}}
```
- `{{if 조건}}`과 `{{/if}}` 사이가 넣거나 뺄 글입니다.
- `{{else}}`는 없어도 됩니다. 없으면 조건이 안 맞을 때 아무것도 남지 않습니다.
- 고르지 않은 쪽 안의 매크로는 실행되지 않습니다. 안 맞는 쪽에 `{{setvar}}`가 있어도 값이 저장되지 않습니다.
**조건이 맞는지(참인지) 판단하는 법**
조건 자리의 값이 빈칸이거나 `false`, `off`, `0`이면 **안 맞음(거짓)**, 그 밖의 모든 값은 **맞음(참)** 입니다. 대문자로 써도 같습니다.
| 조건 자리의 값 | 판단 |
|---|---|
| (빈칸) | 안 맞음 |
| `false`, `off`, `0` | 안 맞음 |
| `true`, `on`, `1` | 맞음 |
| `밝은 성격` 같은 아무 글 | 맞음 |
| `no`, `아니오`, `없음` | **맞음** — 글자가 들어 있으므로 |
그래서 변수에 `no`를 넣어 두고 `{{if .married}}`로 검사하면 "결혼함"으로 처리됩니다. 아니라는 뜻으로 저장할 때는 `false`나 `0`을 쓰세요.
**조건 자리에 쓸 수 있는 것**
1. **값을 칸 없이 꺼내는 매크로의 이름.** `{{` `}}` 없이 이름만 씁니다. 그 매크로의 내용이 있으면 맞음입니다.
```text
{{if description}}[설명] {{description}}{{/if}}
```
카드의 설명 칸에 글이 있으면 `[설명] 밝고 다정한 소꿉친구.`가 남고, 비어 있으면 통째로 사라집니다. 설명이 없을 때 `[설명]` 제목만 덩그러니 남는 것을 막는 용도입니다.
```text
{{if charVersion}}카드 버전 {{charVersion}}{{else}}버전 정보 없음{{/if}}
```
카드에 버전이 `1.2`로 적혀 있으면 `카드 버전 1.2`, 비어 있으면 `버전 정보 없음`.
2. **변수의 축약.** 점(`.`)은 [[채팅 변수]], 달러(`$`)는 [[전역 변수]]입니다. 변수 값이 참이면 맞음입니다.
```text
{{if .hasKey}}{{char}}는 열쇠를 갖고 있다.{{/if}}
{{if $nsfw}}수위 제한 없음.{{/if}}
```
채팅 변수 `hasKey`에 `true`가 들어 있으면 첫 줄이 남습니다. 변수를 만든 적이 없거나 `false`면 사라집니다.
3. **매크로를 통째로 넣기.** 조건 자리에 `{{…}}`를 그대로 넣으면 그 결과로 판단합니다.
```text
{{if {{getvar::showHeader}}}}# 머리말{{/if}}
```
`{{getvar::showHeader}}`가 먼저 변수 값으로 바뀌고, 그 값이 참이면 `# 머리말`이 남습니다. 중괄호가 `}}}}`로 네 개 겹치는 것은 안쪽 매크로의 `}}`와 `if`의 `}}`가 붙어서입니다.
4. **비교 매크로.** 크다·작다·같다는 `{{.이름 비교 값}}` 모양으로 씁니다. 이것이 `true`/`false`로 바뀝니다.
```text
{{if {{.hp <= 30}}}}{{char}}는 숨을 몰아쉰다.{{else}}{{char}}는 아직 여유롭다.{{/if}}
```
채팅 변수 `hp`가 20이면 `가나디는 숨을 몰아쉰다.`, 70이면 `가나디는 아직 여유롭다.`
**`!` — 반대로 뒤집기**
조건 앞에 `!`를 붙이면 "조건이 **안 맞을 때** 넣어라"가 됩니다.
```text
{{if !personality}}성격이 정해지지 않았다.{{/if}}
```
카드의 성격 칸이 **비어 있을 때만** `성격이 정해지지 않았다.`가 남습니다. 성격 칸에 글이 있으면 사라집니다.
**안 되는 것**
```text
{{if hp > 50}}…{{/if}}
{{if affection}}…{{/if}}
```
둘 다 **항상 맞음**으로 처리되어 내용이 늘 남습니다. `hp > 50`이나 `affection`은 매크로 이름도, 축약도 아니라서 그냥 "글자가 있는 값"으로 보기 때문입니다. 변수는 반드시 점을 붙여 `{{.affection}}`, 비교는 `{{.hp > 50}}`처럼 매크로 모양으로 씁니다.
! [[이야기 문자열]] 칸에서는 이 `{{if}}`를 쓰면 안 됩니다. 그 칸은 [[Handlebars]]라는 다른 규칙으로 먼저 처리되기 때문에 `#`을 붙여 `{{#if description}}…{{/if}}`로 써야 합니다. `#` 없이 쓰면 "Error rendering story string" 오류가 뜨고 AI 답이 생성되지 않습니다. 자세한 내용은 아래 "이야기 문자열 전용"에 있습니다.
#0 조건. 위 "조건 자리에 쓸 수 있는 것" 참고
#1 조건이 맞을 때 넣을 글. `{{if}}`와 `{{/if}}` 사이에 쓰며, `{{else}}`로 안 맞을 때의 글을 나눕니다

@else
`{{if}}…{{/if}}` 안에서 "조건이 안 맞을 때"의 글이 시작되는 곳을 표시합니다. `{{if}}` 밖에 쓰면 아무 일도 하지 않습니다.
```text
{{if .isNight}}밤이다.{{else}}낮이다.{{/if}}
```
채팅 변수 `isNight`가 `true`면 `밤이다.`, 아니면 `낮이다.`

@input
채팅 입력창에 **지금 써 있는 글**을 가져옵니다. 보내기 전의 글입니다.
주로 [[빠른 답장]] 버튼 안에서 씁니다. 입력창에 글을 써 두고 버튼을 누르면 그 글을 가져다 쓰는 식입니다.
```stscript
/echo 입력창에 쓴 글: {{input}}
```
입력창에 `오늘 뭐 하지`라고 써 두고 이 버튼을 누르면 알림 `입력창에 쓴 글: 오늘 뭐 하지`가 뜹니다.
! 빠른 답장 버튼 설정의 "사용자 인풋 자동으로 주입하기"가 켜져 있으면 입력창 글이 버튼 내용 앞에 자동으로 붙습니다. `{{input}}`으로 직접 다룰 때는 이 설정을 끄세요.

@maxPrompt
프롬프트에 쓸 수 있는 최대 [[토큰]] 수를 불러옵니다(그 숫자가 이 자리에 들어갑니다). [[컨텍스트|컨텍스트 크기]]에서 [[응답 길이|최대 응답 길이]]를 뺀 값입니다(답을 쓸 자리를 남겨 둔 나머지). 지금 실제로 쓰고 있는 양이 아니라 **설정상 한도**입니다.
```text
최대 {{maxPrompt}}토큰
```
컨텍스트 크기 8192, 최대 응답 길이 400이면:
```result
최대 7792토큰
```

@maxContext
설정해 둔 [[컨텍스트|컨텍스트 크기]](한 번에 AI에게 보낼 수 있는 최대 토큰 수)를 불러옵니다. 위 예라면 `8192`.

@maxResponse
설정해 둔 [[응답 길이|최대 응답 길이]](AI가 한 번에 쓸 수 있는 최대 토큰 수)를 불러옵니다. 위 예라면 `400`.

@reverse
글자 순서를 거꾸로 뒤집습니다.
```text
{{reverse::안녕하세요}}
```
```result
요세하녕안
```
#0 뒤집을 글

@//
[[주석|메모]]를 적는 매크로입니다. AI에게 보내지지 않고 그 자리가 깨끗이 사라집니다. 카드나 프롬프트에 "이 줄은 왜 넣었는지" 같은 메모를 남길 때 씁니다.
```text
{{// 호감도 50 이상이면 말투가 바뀌게 함}}
{{char}}는 상냥하다.
```
```result
가나디는 상냥하다.
```
여러 줄 메모는 `{{//}}`로 열고 `{{///}}`로 닫습니다. 매크로 이름이 `//`라서 닫을 때는 앞에 `/`를 하나 더 붙인 `///`가 됩니다.
```text
{{//}}
메모 첫 줄
메모 둘째 줄
{{///}}
```
#0 메모 내용

@roll
주사위를 굴려 나온 숫자로 바뀝니다. `개수d면수`로 씁니다. `1d20`은 "20면 주사위 1개", `2d6`은 "6면 주사위 2개를 굴려 합친 값"입니다. 뒤에 `+3`처럼 더할 수를 붙일 수 있습니다.
```text
{{roll::1d20}}
{{roll::2d6+3}}
{{roll::6}}
```
| 쓴 것 | 뜻 | 나올 수 있는 값 |
|---|---|---|
| `{{roll::1d20}}` | 20면 주사위 1개 | 1~20 |
| `{{roll::2d6+3}}` | 6면 주사위 2개 + 3 | 5~15 |
| `{{roll::6}}` | 숫자만 쓰면 그 면수 주사위 1개(`1d6`과 같음) | 1~6 |
식을 잘못 쓰면(`{{roll::주사위}}`) 빈칸이 됩니다. 카드·프롬프트에 넣으면 AI에게 보낼 때마다 다시 굴립니다.
#0 주사위 식(예: `1d20`, `2d6+3`)

@random
여러 후보 중 하나를 무작위로 골라 그것으로 바뀝니다. 후보는 `::`로 나눠 씁니다.
```text
오늘 날씨는 {{random::맑음::흐림::비}}.
```
```result
오늘 날씨는 흐림.
```
- 프롬프트가 만들어질 때마다 **새로 고릅니다**. 카드에 넣으면 AI 답을 받을 때마다(스와이프 포함) 날씨가 바뀔 수 있습니다. 한 번 정한 값을 계속 쓰려면 `{{pick}}`을 쓰거나 변수에 저장하세요.
- 옛 표기 `{{random:맑음,흐림,비}}`(쉼표로 구분)도 됩니다. 하지만 후보 안에 쉼표가 있으면 잘못 나뉘므로 `::`를 권합니다.
#0 후보들. `::`로 나눔

@pick
`{{random}}`처럼 후보 중 하나를 고르지만, 한 번 고른 결과가 **바뀌지 않습니다**. 같은 채팅, 같은 칸, 같은 자리라면 프롬프트를 몇 번 다시 만들어도 같은 후보가 나옵니다.
```text
{{char}}의 머리색은 {{pick::금발::갈색::검정}}이다.
```
처음에 `갈색`이 뽑혔다면 그 채팅에서는 계속 `갈색`입니다. 새 채팅을 열면 다시 뽑습니다.
- 다시 뽑고 싶으면 `/reroll-pick` 명령을 씁니다.
- 결과는 그 칸의 **글 전체**를 기준으로 정해지기 때문에, 같은 칸의 다른 글자를 고치면 결과가 바뀔 수 있습니다. 절대 바뀌면 안 되는 값은 [[변수]]에 저장해 두세요.
#0 후보들. `::`로 나눔

@banned
[[Text Completion]] 방식(text-generation-webui 계열)에서만 동작합니다. Chat Completion(OpenAI, Claude, Gemini 등)에서는 써도 아무 효과가 없습니다.
AI가 특정 단어를 쓰지 못하게 막습니다. 매크로를 쓴 자리에는 아무 글자도 남지 않습니다. 단어를 따옴표로 감싸 써도 따옴표는 빠지고 단어만 막습니다.
```text
{{banned::delve}}
```
이 매크로가 들어간 프롬프트로 답을 받을 때 `delve`라는 단어가 나오지 않게 합니다.
! 연결한 프로그램이 금지어 기능을 지원해야 합니다.
#0 막을 단어

@outlet
[[월드 인포]]의 "Outlet"으로 모아 둔 내용을 원하는 자리에 꺼내 놓습니다.
보통 월드 인포 항목은 정해진 위치(캐릭터 정의 전, 캐릭터 정의 후 등)에 자동으로 들어갑니다. 항목의 위치를 **Outlet**으로 정하고 Outlet 이름을 적어 두면, 그 항목은 자동으로 들어가지 않고 `{{outlet::그 이름}}`을 써 둔 곳에 들어갑니다.
1. 월드 인포 항목 "업적 1", "업적 2"의 위치를 Outlet으로, Outlet 이름을 `achievements`로 정합니다.
2. 캐릭터 설명에 아래처럼 씁니다.
```text
[달성한 업적]
{{outlet::achievements}}
```
켜진 업적 항목들의 내용이 `[달성한 업적]` 아래에 모입니다. 켜진 항목이 없으면 빈칸입니다.
! 로어북 이름이나 항목 제목으로 꺼내는 기능이 아닙니다. 항목에 적은 **Outlet 이름**과 같아야 합니다.
#0 Outlet 이름

@user
내 이름(지금 쓰는 [[페르소나]]의 이름)으로 바뀝니다.
```text
{{char}}는 {{user}}의 손을 잡았다.
```
```result
가나디는 챗시의 손을 잡았다.
```

@char
지금 대화하는 캐릭터의 이름으로 바뀝니다. [[그룹 채팅]]에서는 지금 말할 차례인 캐릭터의 이름입니다.
```text
{{char}}: 안녕!
```
```result
가나디: 안녕!
```

@group
[[그룹 채팅]]에 있는 캐릭터들의 이름을 쉼표로 이어 붙인 것으로 바뀝니다. 음소거된 멤버도 들어갑니다. 1:1 채팅에서는 그 캐릭터 이름 하나입니다.
```text
지금 함께 있는 사람: {{group}}
```
가나디, 끼끼, 도다리가 있는 그룹이라면:
```result
지금 함께 있는 사람: 가나디, 끼끼, 도다리
```
! 숨은 별칭 `{{charIfNotGroup}}`도 `{{group}}`과 똑같이 동작합니다. 이름만 보면 "그룹이 아닐 때만 캐릭터 이름"일 것 같지만 그룹에서도 이름 목록이 나오므로, 그룹인지 가려내는 용도로는 쓸 수 없습니다.

@groupNotMuted
`{{group}}`과 같지만 음소거된 멤버를 뺀 이름 목록입니다. 위 예에서 도다리가 음소거라면 `가나디, 끼끼`. 1:1 채팅에서는 캐릭터 이름입니다.

@notChar
지금 말할 차례인 캐릭터를 **뺀** 나머지 이름입니다.
- [[그룹 채팅]]: 지금 차례인 캐릭터와 음소거된 멤버를 뺀 다른 캐릭터들의 이름. 내 이름은 들어가지 않습니다.
- 1:1 채팅: 내 이름(`{{user}}`).
```text
{{char}}가 {{notChar}} 쪽을 바라본다.
```
가나디·끼끼·도다리가 있는 그룹에서 가나디 차례라면:
```result
가나디가 끼끼, 도다리 쪽을 바라본다.
```
1:1 채팅이라면:
```result
가나디가 챗시 쪽을 바라본다.
```

@charPrompt
캐릭터 카드에 따로 적어 둔 **주요 프롬프트**로 바뀝니다. 캐릭터 편집 화면의 **고급 정의** → **프롬프트 무시** 묶음에 있는 "주요 프롬프트" 칸입니다. 그 칸이 비어 있으면 빈칸입니다.
이 칸에 글을 적으면, 그 캐릭터와 대화할 때는 원래 쓰던 주요 프롬프트(시스템 프롬프트) 대신 이 글이 쓰입니다.

@charInstruction
캐릭터 카드에 따로 적어 둔 Post-History Instructions(채팅 기록 **뒤**에 붙는 지시문)로 바뀝니다. 캐릭터 편집 화면의 **고급 정의** → **프롬프트 무시** 묶음에 있는 "Post-History Instructions" 칸입니다. 이 칸 이름은 한국어 화면에서도 영어로 나옵니다. 그 칸이 비어 있으면 빈칸입니다.

@charDescription
캐릭터 카드의 **캐릭터 설명** 칸 내용으로 바뀝니다. 짧게 `{{description}}`만 써도 똑같이 동작합니다(별칭).
```text
[캐릭터 설명]
{{description}}
```
설명 칸에 `밝고 다정한 소꿉친구.`라고 적혀 있다면:
```result
[캐릭터 설명]
밝고 다정한 소꿉친구.
```
설명 칸이 비어 있을 때 제목까지 함께 빼는 방법은 매크로 문법의 "종합 예제"에 있습니다.

@charPersonality
캐릭터 카드의 **성격 요약** 칸(고급 정의 안에 있음) 내용으로 바뀝니다. 짧게 `{{personality}}`만 써도 똑같이 동작합니다(별칭).

@charScenario
캐릭터 카드의 **시나리오** 칸(고급 정의 안에 있음) 내용으로 바뀝니다. 짧게 `{{scenario}}`만 써도 똑같이 동작합니다(별칭).

@persona
지금 쓰는 [[페르소나]]의 **설명**으로 바뀝니다. 이름이 아니라 설명입니다. 이름은 `{{user}}`입니다.
```text
[{{user}}에 대한 정보]
{{persona}}
```
```result
[챗시에 대한 정보]
20대 대학생. 말수가 적다.
```

@mesExamplesRaw
캐릭터 카드의 **대화 예시** 칸(고급 정의 안에 있음)에 적힌 글을 손대지 않고 그대로 넣습니다. `<START>` 같은 표시도 그대로 남습니다.

@mesExamples
대화 예시를 AI에게 보낼 모양으로 다듬은 것으로 바뀝니다. 고급 서식의 [[지시 모드]]가 켜져 있으면 그 표시가 붙은 모양입니다. 적은 글 그대로를 원하면 `{{mesExamplesRaw}}`를 씁니다.

@charDepthPrompt
캐릭터 카드의 **캐릭터 노트** 칸(고급 정의 안에 있음) 내용으로 바뀝니다. 캐릭터 노트는 채팅 기록 중간의 정해진 [[깊이]]에 끼워 넣도록 적어 두는 캐릭터 전용 메모입니다.

@charCreatorNotes
캐릭터 카드의 **제작자의 메모** 칸(고급 정의 안에 있음) 내용으로 바뀝니다. 짧게 `{{creatorNotes}}`만 써도 똑같이 동작합니다(별칭).

@charFirstMessage
캐릭터 카드에 저장된 **첫 번째 메시지**(첫 번째 메시지)로 바뀝니다. 짧게 `{{greeting}}`만 써도 똑같이 동작합니다(별칭).
숫자를 주면 대체 인사말을 고릅니다. `0`(또는 비움)은 기본 첫 번째 메시지, `1`은 첫 번째 대체 인사말, `2`는 두 번째입니다.
```text
{{greeting}}
{{greeting::1}}
```
첫 줄은 기본 첫 번째 메시지, 둘째 줄은 첫 번째 대체 인사말로 바뀝니다. 없는 번호를 쓰면 빈칸입니다.
! 지금 채팅의 첫 메시지가 아니라 **카드에 저장된** 글입니다. 채팅을 시작할 때 다른 첫 번째 메시지을 골랐거나 첫 메시지를 고쳤어도 카드에 적힌 글이 나옵니다.
#0 첫 번째 메시지 번호. 비우거나 `0` = 기본 첫 번째 메시지, `1`부터 = 대체 인사말

@charVersion
캐릭터 카드에 적힌 **캐릭터 버전** 칸(고급 정의 안에 있음. 제작자가 적는 카드 버전, 예: `1.2`)으로 바뀝니다. SillyTavern 프로그램의 버전이 아닙니다. 숨은 별칭 `{{version}}`, `{{char_version}}`도 같습니다.

@model
지금 [[API]] 연결 화면에서 골라 둔 AI 모델의 이름을 불러옵니다(예: `claude-sonnet-4-5`, `gpt-4o`). 모델을 바꾸는 매크로가 아니라, 이름을 글자로 가져올 뿐입니다.
```stscript
/echo 지금 모델: {{model}}
```
알림 `지금 모델: gpt-4o`처럼 뜹니다.

@original
캐릭터 카드의 **프롬프트 무시** 칸(고급 정의 안의 "주요 프롬프트", "Post-History Instructions") 안에서만 쓰는 매크로입니다. 그 자리에 **원래 쓰던 프롬프트**를 넣습니다.
캐릭터 카드의 주요 프롬프트 칸에 글을 쓰면, 원래 쓰던 주요 프롬프트 대신 그 글이 쓰입니다(원래 것은 무시됨). 원래 것을 버리지 않고 뒤에 한 줄 덧붙이고 싶을 때 `{{original}}`을 씁니다.
```text
{{original}}
이 캐릭터는 반말로만 말한다.
```
원래 주요 프롬프트가 `너는 소설 작가다.`라면:
```result
너는 소설 작가다.
이 캐릭터는 반말로만 말한다.
```
한 칸 안에 `{{original}}`을 여러 번 써도 원래 내용은 한 번만 들어갑니다.

@isMobile
지금 SillyTavern을 휴대폰·태블릿에서 열었는지 알려 줍니다. 휴대폰·태블릿이면 `true`, 컴퓨터면 `false`라는 글자가 이 자리에 들어갑니다. `{{if}}`와 함께 써서 기기마다 다른 글을 넣을 수 있습니다.
```text
{{if {{isMobile}}}}짧게 써라.{{else}}자세히 써라.{{/if}}
```
휴대폰에서는 `짧게 써라.`, 컴퓨터에서는 `자세히 써라.`가 남습니다.

@lastGenerationType
마지막으로 AI에게 답을 요청한 방식을 불러옵니다. 아래 값 중 하나가 이 자리에 들어갑니다.
| 값 | 뜻 |
|---|---|
| `normal` | 평소처럼 전송 |
| `swipe` | 스와이프로 다른 답 받기 |
| `regenerate` | 재생성 |
| `continue` | 계속 생성하기 |
| `impersonate` | 사칭(AI가 내 메시지를 대신 쓰기) |
| `quiet` | 화면에 안 보이는 생성(`/gen` 등) |
아직 생성한 적이 없거나 채팅을 바꿨으면 빈칸입니다.
```stscript
/echo 마지막 생성 방식: {{lastGenerationType}}
```
방금 스와이프로 답을 받았다면 알림 `마지막 생성 방식: swipe`가 뜹니다.

@hasExtension
[[확장]]이 설치되어 있고 켜져 있는지 알려 줍니다. 켜져 있으면 `true`, 없거나 꺼져 있으면 `false`라는 글자가 이 자리에 들어갑니다.
```text
{{if {{hasExtension::SillyTavern-LALib}}}}LALib 사용 가능{{else}}LALib 없음{{/if}}
```
#0 확장 이름. 확장 메뉴에 보이는 이름이나 폴더 이름(예: `SillyTavern-LALib`)
