#1 기본값

@import
다른 [[빠른 답장]] 버튼 안에 만들어 둔 [[클로저]]를 **가져와서** 씁니다. 자주 쓰는 클로저를 "도구 모음" 버튼 하나에 모아 두고 여러 버튼에서 가져다 쓰는 용도입니다.
1. `도구` 세트의 `모음` 버튼 내용에 `/let greet {: /echo 안녕 :}`처럼 클로저를 만들어 둡니다.
2. 다른 버튼에서 가져와 씁니다.
```stscript
/import from=도구.모음 greet |
/:greet
```
```stscript
/import from=도구.모음 greet as 인사 |
/:인사
```
둘째 예는 `greet`를 `인사`라는 이름으로 바꿔 가져옵니다. 여러 개는 빈칸이나 줄바꿈으로 나열합니다: `greet bye`.
! 그 버튼 안에서 `/let`이나 `/var`로 범위 변수에 직접 넣은 클로저만 가져올 수 있습니다.
.from 가져올 버튼(`세트이름.라벨`)

@db-ingest
데이터 저장소의 모든 파일을 지금 바로 **검색용으로 준비**(벡터화)합니다. 벡터 저장소 [[확장]]이 켜져 있어야 합니다. 벡터화는 글을 "뜻이 비슷한 것끼리 찾을 수 있는" 숫자 모양으로 바꿔 두는 것입니다.

@db-purge
데이터 저장소 파일들의 검색용 준비(벡터화) 결과를 모두 지웁니다. 파일 자체는 지우지 않습니다.

@db-search
데이터 저장소에서 검색어와 **뜻이 비슷한** 내용이 든 파일을 찾아 결과로 남깁니다(벡터 저장소 확장).
```stscript
/db-search 주인공의 고향 | /echo
/db-search return=chunks 주인공의 고향 | /echo
```
첫 줄은 관련 파일 주소 목록, 둘째 줄은 찾은 **글 조각** 자체를 알림으로 띄웁니다.
.threshold 얼마나 비슷해야 찾을지(0~1). 비우면 전체 설정값
.count 최대 몇 개를 돌려줄지
.source 이 범위만 검색: `global`(공통), `character`(지금 캐릭터), `chat`(지금 채팅)
=chunks 파일 주소 대신 찾은 글 조각을 돌려줌

@checkpoint-create

.mesId 메시지 번호. 비우면 마지막 메시지

#0 역할

@persona-create
새 [[페르소나]]를 만들고, 그 [[아바타 키]]를 결과로 남깁니다. `name=`만 꼭 써야 합니다.
```stscript
/persona-create name=챗시 description="20대 대학생. 말수가 적다."
```
```stscript
/persona-create name=탐정 avatar=prompt lorebook=추리설정 select=false
```
`avatar=prompt`라서 파일 선택 창이 뜹니다. 거기서 고른 그림이 아바타가 됩니다. `추리설정` 로어북을 연결하고, `select=false`라서 지금 쓰는 페르소나는 바꾸지 않습니다.
! `avatar=`에는 `prompt`(파일 선택 창), SillyTavern 안의 경로, `/imagine`의 결과 등을 씁니다. 비우면 기본 아바타.
.name 페르소나 이름
.description 페르소나 설명(AI에게 보내짐)
.title 화면에만 보이는 부제목(AI에게 보내지지 않음)
.avatar 아바타 그림
.avatarPromptResize 그림을 올릴 때 자르기 창을 띄울지
.descriptionPosition 페르소나 설명을 프롬프트 어디에 넣을지
=inPrompt 프롬프트 안(기본)
=topAN 작가 노트 위
=bottomAN 작가 노트 아래
=atDepth 정한 깊이에(`descriptionDepth=`, `descriptionRole=`)
=none 넣지 않음
.descriptionDepth `atDepth`일 때의 깊이
.descriptionRole `atDepth`일 때 누구의 말로 넣을지
.lorebook 이 페르소나에 연결할 로어북
.select 만든 뒤 바로 이 페르소나로 바꿀지

@persona-delete
[[페르소나]]와 그 아바타를 **지웁니다**. 되돌릴 수 없습니다.
```stscript
/persona-delete persona=탐정
```
.persona 지울 페르소나. 비우면 지금 페르소나
.silent 묻는 창 없이 바로 지움

@persona-duplicate
[[페르소나]]를 통째로 복사하고, 복사본의 아바타 키를 결과로 남깁니다.
```stscript
/persona-duplicate | /persona-update persona="{{pipe}}" name="챗시 2"
```
지금 페르소나를 복사하고, 복사본 이름을 `챗시 2`로 바꿉니다.
.persona 복사할 페르소나. 비우면 지금 페르소나
.select 복사한 뒤 복사본으로 바꿀지

@persona-lock
지금 [[페르소나]]를 **고정**합니다. 고정해 두면 그 채팅(또는 캐릭터)을 열 때 저절로 이 페르소나가 됩니다. 값 없이 쓰면 지금 고정 상태를 결과로 남깁니다. 다른 이름 `/lock`, `/bind`.
```stscript
/persona-lock on
/persona-lock type=character on
/persona-lock type=default on
```
| 줄 | 하는 일 |
|---|---|
| 1 | 이 채팅에 고정 |
| 2 | 지금 캐릭터에 고정(이 캐릭터와의 모든 채팅) |
| 3 | 새 채팅의 기본 페르소나로 |
.type 어디에 고정할지
=chat 지금 채팅
=character 지금 캐릭터
=default 새 채팅의 기본값
#0 `on`(고정), `off`(풀기), `toggle`(반대로)

@persona-set
이름이나 아바타 키로 [[페르소나]]를 바꿉니다. 다른 이름 `/persona`, `/name`.
```stscript
/persona-set 탐정
/persona-set mode=lookup 탐정
```
첫 줄은 `탐정` 페르소나로 바꾸되, 그런 페르소나가 없으면 이름만 잠깐 `탐정`으로 씁니다. 둘째 줄은 있을 때만 바꿉니다.
.mode 찾는 방법
=lookup 있는 페르소나에서만 찾음
=temp 찾지 않고 이름만 잠깐 바꿈
=all 먼저 찾고, 없으면 이름만 잠깐 바꿈(기본)
#0 페르소나 이름 또는 아바타 키

@persona-sync
채팅 속 **내 메시지**들의 이름·아바타를 지금 페르소나로 맞춥니다. 페르소나를 잘못 고른 채로 채팅을 진행하다가 나중에 알아챘을 때, 이미 보낸 메시지들을 올바른 페르소나의 것으로 고치는 용도입니다. 다른 이름 `/sync`.
```stscript
/persona-sync
/persona-sync from=옛이름 0-20
```
먼저 올바른 페르소나를 고른 뒤 실행합니다. 첫 줄은 모든 내 메시지를, 둘째 줄은 0~20번 중 `옛이름`으로 보낸 것만 지금 페르소나의 이름·아바타로 바꿉니다.
.from 이 이름으로 보낸 메시지만 바꿈
.quiet `false`면 바꾸기 전에 확인 창을 띄움

#0 추론 내용

@reasoning-parse
글에서 생각 과정(추론) 부분과 본문을 **나눕니다**. 추론을 감싸는 표시(예: `<think>` … `</think>`)는 고급 서식(A 아이콘) 화면의 추론 서식 설정을 따릅니다. 다른 이름 `/parse-reasoning`.
```stscript
/reasoning-parse <think>날씨부터 말하자.</think>오늘은 맑아. | /echo
/reasoning-parse return=content <think>날씨부터 말하자.</think>오늘은 맑아. | /echo
```
첫 줄은 알림 `날씨부터 말하자.`(추론 부분), 둘째 줄은 `오늘은 맑아.`(본문).
.regex 추론 부분에 정규식 스크립트를 적용할지
.return 무엇을 돌려줄지: `reasoning`(추론 부분, 기본) 또는 `content`(추론을 뺀 본문)
.strict 추론 부분이 글 맨 앞에 있을 때만 추론으로 인정
#0 나눌 글

@reasoning-format
추론과 본문을 추론 표시 설정으로 **합쳐** 한 덩어리 글로 만듭니다. `/reasoning-parse`로 다시 나눌 수 있는 모양이 됩니다. 다른 이름 `/format-reasoning`.
```stscript
/reasoning-format reasoning="날씨부터 말하자." 오늘은 맑아. | /echo
```
알림 `<think>날씨부터 말하자.</think>오늘은 맑아.` 같은 글(설정한 표시에 따라 다름).
.reasoning 추론(생각) 부분
