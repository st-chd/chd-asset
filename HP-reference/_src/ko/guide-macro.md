## 매크로 문법

[[매크로]]는 글 속에 `{{ }}`로 써 두면 다른 글자로 바뀌는 표시입니다. "처음 시작하기"에서 본 `{{user}}`(내 이름), `{{char}}`(캐릭터 이름)가 매크로입니다. 예제 속 이름은 앞과 같이 내 이름이 챗시, 캐릭터 이름이 가나디입니다.

이 설명은 위에서부터 차례로 읽도록 썼습니다. 쓰는 모양 → 변수 → 조건 순서로 배우고, 그 뒤의 항목은 앞에서 배운 것만 써서 설명합니다.

### 매크로가 동작하는 곳

매크로는 아무 데나 쓴다고 바뀌지 않습니다. SillyTavern이 "이 칸은 매크로를 바꿔서 쓴다"고 정해 둔 곳에서만 바뀝니다.

| 쓰는 곳 | 바뀌는 때 |
|---|---|
| [[캐릭터 카드]]의 설명·성격 요약·시나리오·첫 번째 메시지·대화 예시 | AI에게 보낼 [[프롬프트]]를 만들 때 |
| [[시스템 프롬프트]], [[작가 노트]], [[월드 인포]] 항목 내용 | 프롬프트를 만들 때 |
| 채팅 입력창에 쓴 평범한 메시지 | 전송할 때 |
| [[슬래시 명령]]의 인자 | 그 명령이 실행되기 직전 |
| [[빠른 답장]] 버튼 내용 | 버튼을 누를 때 |

프롬프트는 AI에게 답을 받을 때마다 새로 만들어지므로, 카드나 프롬프트 속 매크로는 **답을 받을 때마다 다시** 바뀝니다. 그래서 무작위로 고르는 매크로는 매번 다른 결과가 나옵니다.

지금 쓸 수 있는 매크로 전체 목록은 채팅 입력창에 `/? macros`를 입력하면 볼 수 있습니다. 입력창에 `{{`를 치면 이름 목록도 뜹니다.

이 문서는 [[새 매크로 엔진]] 기준입니다. 사용자 설정의 Experimental Macro Engine 항목이 켜져 있어야 하며, 따로 끄지 않았다면 켜져 있습니다.

### 매크로를 쓰는 모양 {#mg-shape}

매크로는 이름과 [[칸]]으로 되어 있습니다. 칸은 매크로에 넘겨주는 값입니다. 칸이 필요 없는 매크로는 이름만 씁니다.

| 모양 | 예 | 뜻 |
|---|---|---|
| 이름만 | `{{user}}` | 칸이 없는 매크로. 내 이름으로 바뀜 |
| `::` 뒤에 칸 하나 | `{{roll::1d20}}` | 이름 `roll`, 칸 `1d20`. 20면 주사위 1개를 굴린 숫자로 바뀜 |
| `::`로 칸 여러 개 | `{{random::맑음::흐림::비}}` | 칸이 셋. 셋 중 하나로 바뀜 |
| 이름 뒤 공백 한 칸 | `{{roll 1d20}}` | 공백 뒤 전부가 칸 **하나**. `{{roll::1d20}}`과 같음 |

칸이 둘 이상이면 반드시 `::`를 씁니다. 공백 한 칸 뒤에는 칸을 **하나만** 쓸 수 있습니다.

```text
{{roll::2d6}}                칸 하나 → 됨
{{roll 2d6}}                 칸 하나 → 됨
{{random::맑음::흐림}}        칸 둘 → 둘 중 하나가 나옴
{{random 맑음 흐림}}          "맑음 흐림"이 칸 하나로 붙음 → 늘 "맑음 흐림"만 나옴
```

`::`가 아닌 `:` 하나는 칸을 나누지 않습니다. 칸 안에 든 `:`는 그냥 글자입니다.

```text
{{time::UTC+9}}              칸 하나 → UTC+9
{{datetimeformat::HH:mm}}    칸 하나 → HH:mm (가운데 : 는 글자)
```

- 매크로 **이름**은 대소문자를 가리지 않습니다. `{{USER}}`와 `{{user}}`는 같습니다.
- 칸에 넣는 값은 대소문자를 가립니다.

### 변수: 값을 저장했다 꺼내 쓰기 {#mg-var}

[[변수]]는 이름표를 붙여 값을 넣어 두는 칸입니다. 체력, 호감도, 날씨처럼 대화 중에 바뀌는 값을 기억해 둘 때 씁니다. 저장은 `{{setvar}}`, 꺼내기는 `{{getvar}}`로 합니다.

```text
{{setvar::hp::100}}{{char}}의 체력은 {{getvar::hp}}이다.
```

1. `{{setvar::hp::100}}` — `hp`라는 이름의 변수에 `100`을 저장합니다. 저장만 하는 매크로라서 글에는 아무 글자도 남기지 않습니다. 값 `100`은 변수 안에 잘 들어 있습니다.
2. `{{getvar::hp}}` — 변수 `hp`에 든 값 `100`을 꺼내 그 자리에 넣습니다.

AI에게는 이렇게 전달됩니다.

```result
가나디의 체력은 100이다.
```

`{{setvar}}`는 칸이 둘(이름, 값)이라 반드시 `::`로 나눕니다. `{{setvar hp 100}}`은 `hp 100`이 칸 하나로 붙고, `{{setvar:hp:100}}`도 칸이 나뉘지 않아 둘 다 저장되지 않습니다.

매크로로 다루는 변수는 두 종류입니다.

| 종류 | 남아 있는 범위 | 저장 | 꺼내기 | 꺼내기 축약 |
|---|---|---|---|---|
| [[채팅 변수]] | 지금 채팅에서만. 다른 채팅에는 없음 | `{{setvar::hp::100}}` | `{{getvar::hp}}` | `{{.hp}}` |
| [[전역 변수]] | 모든 채팅·캐릭터 공통 | `{{setglobalvar::gold::50}}` | `{{getglobalvar::gold}}` | `{{$gold}}` |

- **축약**은 긴 매크로를 짧게 쓰는 방법입니다. `{{.hp}}`는 `{{getvar::hp}}`와 완전히 같고, `{{$gold}}`는 `{{getglobalvar::gold}}`와 같습니다. 점(`.`)은 채팅 변수, 달러(`$`)는 전역 변수를 뜻합니다. 축약에는 영어로 된 변수 이름만 쓸 수 있습니다. 더하기·비교 같은 나머지 축약은 아래 [변수 축약 문법](#m-short) 카드에 있습니다.
- 꺼내려는 변수에 값을 저장한 적이 없으면(`{{setvar}}`나 `/setvar` 명령을 한 번도 쓰지 않았으면) 그 자리는 빈칸이 됩니다.
- 변수 이름은 대소문자를 구분합니다. `hp`와 `HP`는 서로 다른 변수입니다.
- 스크립트에서 명령으로 변수를 다루는 법은 [STscript의 변수](#st-var)에서 배웁니다. 같은 변수를 매크로와 명령 양쪽에서 쓸 수 있습니다.

#### 카드·프롬프트에 저장 매크로를 둘 때

`{{setvar}}`처럼 값을 바꾸는 매크로를 캐릭터 카드나 프롬프트에 넣으면 **프롬프트를 만들 때마다** 실행됩니다. 스와이프로 답을 다시 받을 때도 또 실행됩니다.

```text
{{setvar::hp::100}}
```

이것을 캐릭터 설명에 두면, 대화 중에 체력을 30으로 줄여 놓아도 다음 답을 받는 순간 다시 100이 됩니다.

- 값을 바꾸는 일은 보통 명령([[빠른 답장]] 버튼)으로 하고, 카드와 프롬프트에서는 꺼내 쓰기만 합니다.
- 카드에서 "처음 한 번만" 값을 정하고 싶으면 `체력: {{.hp ??= 100}}`처럼 씁니다. "변수 `hp`가 **아직 없을 때만** 100을 저장하라"는 축약입니다. 이미 값이 있으면 건드리지 않습니다. 이 매크로는 그 자리에 변수 값(처음엔 `100`, 그 뒤엔 지금 값)을 남기므로, 값이 보일 자리에 둡니다.

### 조건: `{{if}}` {#mg-if}

조건에 따라 글을 넣거나 뺍니다.

```text
{{if {{.hp <= 30}}}}
{{char}}는 숨을 몰아쉬며 비틀거린다.
{{else}}
{{char}}는 아직 여유가 있다.
{{/if}}
```

변수 `hp`가 70일 때 처리되는 순서입니다.

1. 안쪽의 `{{.hp <= 30}}`이 먼저 처리됩니다. "채팅 변수 `hp`가 30보다 작거나 같은가"를 비교해서 맞으면 `true`, 틀리면 `false`라는 글자로 바뀝니다. 70은 30보다 크므로 `false`입니다.
2. 바깥은 `{{if false}}`가 됩니다. 거짓이므로 `{{else}}` **뒤**의 글만 남습니다.

```result
가나디는 아직 여유가 있다.
```

- 참이면 `{{if}}`와 `{{else}}` 사이가, 거짓이면 `{{else}}`와 `{{/if}}` 사이가 남습니다.
- `{{else}}`는 없어도 됩니다. 없으면 거짓일 때 아무것도 남지 않습니다.
- 무엇이 참이고 거짓인지는 [[참과 거짓]]에 있습니다. 거짓은 빈칸·`false`·`off`·`0` 네 가지뿐입니다.

비교에 쓰는 기호입니다. 모두 `{{.변수이름 기호 값}}` 모양으로 씁니다.

| 기호 | 뜻 | `hp`가 70일 때 |
|---|---|---|
| `==` | 같다 | `{{.hp == 70}}` → `true` |
| `!=` | 다르다 | `{{.hp != 70}}` → `false` |
| `>` | 왼쪽이 더 크다 | `{{.hp > 30}}` → `true` |
| `>=` | 왼쪽이 크거나 같다 | `{{.hp >= 70}}` → `true` |
| `<` | 왼쪽이 더 작다 | `{{.hp < 30}}` → `false` |
| `<=` | 왼쪽이 작거나 같다 | `{{.hp <= 30}}` → `false` |

**변수 이름 앞의 점(`.`)을 빼먹으면 안 됩니다.** 점은 "이것은 채팅 변수다"라는 표시입니다(전역 변수는 `$`).

| 쓴 것 | 일어나는 일 |
|---|---|
| `{{if {{.hp <= 30}}}}` | 변수 `hp`를 30과 비교함. 올바른 모양 |
| `{{if hp <= 30}}` | 비교하지 않음. `hp <= 30`을 그냥 글자로 보고, 글자가 있으니 **항상 참** |
| `{{if .hp}}` | 변수 `hp`의 값이 참일 때 남김 |
| `{{if hp}}` | `hp`를 그냥 글자로 봄. **항상 참** |

**조건 앞에 `!`를 붙이면 참과 거짓이 뒤바뀝니다.** "이 조건이 **아닐 때** 남겨라"가 됩니다.

```text
{{if .hasKey}}열쇠를 갖고 있다.{{/if}}
{{if !.hasKey}}열쇠가 없다.{{/if}}
```

| 변수 `hasKey`의 값 | 남는 글 |
|---|---|
| `true` | `열쇠를 갖고 있다.` |
| `false`, `0`, 빈칸, 또는 저장한 적 없음 | `열쇠가 없다.` |

조건 자리에 쓸 수 있는 것 전체와 더 많은 예는 `{{if}}` 카드에 있습니다.

### 매크로 안의 매크로, 블록 {#mg-block}

| 모양 | 예 | 뜻 |
|---|---|---|
| 매크로 안에 매크로 | `{{getvar::{{char}}_기분}}` | 안쪽이 먼저 바뀜([[중첩]]) |
| 여는 것과 닫는 것 사이에 내용 | `{{setvar::메모}}긴 글{{/setvar}}` | 사이의 글이 마지막 칸으로 들어감([[블록]]) |

**매크로 안에 매크로**를 넣으면 안쪽이 먼저 바뀌고, 그 결과를 가지고 바깥쪽이 바뀝니다.

```text
{{getvar::{{char}}_기분}}
```

1. 안쪽 `{{char}}`가 먼저 `가나디`로 바뀌어 `{{getvar::가나디_기분}}`이 됩니다.
2. 바깥쪽이 변수 `가나디_기분`의 값으로 바뀝니다.

위 "조건"의 `{{if {{.hp <= 30}}}}`도 같은 방식입니다. 닫는 중괄호가 `}}}}`로 네 개 겹치는 것은 안쪽 매크로의 `}}`와 `if`의 `}}`가 붙어서입니다.

**블록**은 여는 매크로와 닫는 매크로 사이에 내용을 넣는 방식입니다. 닫는 쪽은 이름 앞에 `/`를 붙입니다. `{{if}}…{{/if}}`가 블록입니다. 사이의 글은 그 매크로의 마지막 칸으로 들어가므로, 아래 둘은 같습니다.

```text
{{setvar::메모::긴 글}}
{{setvar::메모}}긴 글{{/setvar}}
```

여러 줄짜리 긴 글을 넣을 때 블록이 편합니다. 블록으로 쓸 수 있는 매크로는 `{{if}}`, `{{setvar}}`, `{{trim}}` 등 일부입니다.

### 어떤 순서로 바뀌나

1. 매크로 안에 매크로가 있으면 **안쪽부터** 바뀝니다.
2. 같은 줄에 여러 개 있으면 **왼쪽부터** 바뀝니다.
3. `{{if}}`는 조건에 맞는 쪽만 바꾸고, 고르지 않은 쪽 안의 매크로는 아예 실행하지 않습니다.

```text
{{setvar::n::1}}처음 값은 {{getvar::n}}, {{setvar::n::2}}나중 값은 {{getvar::n}}
```

결과는 이렇습니다.

```result
처음 값은 1, 나중 값은 2
```

왼쪽부터 처리되므로 첫 `{{getvar::n}}`은 그때까지 저장된 `1`을, 두 번째는 그 사이에 다시 저장된 `2`를 꺼냅니다.

### 블록 안의 공백

[[블록]]으로 쓴 내용은 앞뒤의 빈 줄과 빈칸이 자동으로 지워집니다. 내용 첫 줄 앞에 빈칸이 있으면, 그 개수만큼 모든 줄의 앞쪽 빈칸(들여쓰기)도 지워집니다.

```text
{{setvar::인사}}
    안녕하세요
    반갑습니다
{{/setvar}}
```

변수 `인사`에는 이렇게 저장됩니다(맨 앞뒤 빈 줄과 앞쪽 빈칸 4개가 없어짐).

```result
안녕하세요
반갑습니다
```

지우지 않고 **쓴 그대로** 두려면 여는 쪽 이름 앞에 `#`을 붙입니다.

```text
{{#setvar::인사}}
    안녕하세요
{{/setvar}}
```

이번에는 첫 줄바꿈, 앞쪽 빈칸 4개, 끝 줄바꿈까지 그대로 저장됩니다.

여기서 `#`은 "공백을 지우지 마라"는 표시일 뿐입니다. 고급 서식의 [[이야기 문자열]] 칸에서 쓰는 `{{#if}}`의 `#`과는 뜻이 다릅니다(아래 [이야기 문자열 전용](#m-story) 참고).

### 이름 앞에 붙는 기호

| 기호 | 예 | 하는 일 |
|---|---|---|
| `/` | `{{/if}}` | 블록을 닫음 |
| `#` | `{{#setvar::x}}` | 블록 내용의 공백을 지우지 않음 |
| `!` `?` `~` `>` | `{{!user}}` | 아무 일도 하지 않음. `{{user}}`와 똑같이 바뀜 |

`!` `?` `~` `>`는 SillyTavern이 나중에 새 기능에 쓰려고 자리만 잡아 둔 기호입니다. 지금은 붙여도 달라지는 것이 없고, 나중에 뜻이 생기면 동작이 바뀔 수 있으니 이름 앞에는 붙이지 않는 것이 좋습니다.

`{{if !.hp}}`처럼 `if`의 **조건 앞**에 붙는 `!`는 이 표와 다른 것입니다. 위 "조건"에서 배운 "참과 거짓 뒤집기"입니다.

### 매크로를 바꾸지 않고 글자 그대로 쓰기

`{{user}}`라는 글자 자체를 보여 주고 싶으면 중괄호 앞에 `\`를 붙입니다([[이스케이프]]).

```text
매크로는 \{\{user\}\}처럼 씁니다.
```

```result
매크로는 {{user}}처럼 씁니다.
```

### 옛 표기

예전 SillyTavern에서 쓰던 모양입니다. 아래 표의 옛 표기는 **지금도 모두 동작합니다**. 오래된 캐릭터 카드나 프롬프트에 남아 있어도 고칠 필요는 없고, 새로 쓸 때만 오른쪽 모양을 쓰면 됩니다.

| 옛 표기 | 지금 표기 | 지금도 동작하나 |
|---|---|---|
| `<USER>` | `{{user}}` | 동작함. 소문자 `<user>`도 됨 |
| `<BOT>`, `<CHAR>` | `{{char}}` | 동작함. 소문자도 됨 |
| `<GROUP>`, `<CHARIFNOTGROUP>` | `{{group}}` | 동작함 |
| `{{time_UTC+9}}` | `{{time::UTC+9}}` | 동작함 |
| `{{idle_duration}}` | `{{idleDuration}}` | 동작함 |
| `{{roll:1d20}}` | `{{roll::1d20}}` | 동작함. `:` 하나 뒤는 통째로 칸 하나 |
| `{{random:맑음,흐림}}` | `{{random::맑음::흐림}}` | 동작함. 쉼표로 나눔 |
| `{{datetimeformat YYYY}}` | `{{datetimeformat::YYYY}}` | 동작함 |

반대로 `{{if}}`, 블록, `{{.hp}}` 같은 축약, `{{space::3}}`, `{{hasvar}}` 등은 새 매크로 엔진에서만 됩니다.

### 매크로가 안 바뀌거나 빈칸이 될 때 {#mg-trouble}

위에서부터 하나씩 확인하세요.

1. **그 칸이 매크로를 바꿔 주는 곳인지.** 위 "매크로가 동작하는 곳" 표에 없는 입력칸이면 글자 그대로 남습니다.
2. **중괄호가 맞는지.** `{{user}`, `{user}}`, `{[user}]`는 매크로가 아닙니다. 양쪽에 `{{`, `}}` 두 겹씩입니다.
3. **칸 나누기가 맞는지.** 칸이 둘 이상이면 `::`. `{{setvar hp 10}}`, `{{setvar:hp:10}}`은 안 됩니다.
4. **값이 있는지.** `{{getvar::hp}}`는 변수 `hp`에 값을 저장한 적이 없으면 빈칸입니다. `{{charScenario}}`는 카드의 시나리오 칸이 비어 있으면 빈칸입니다.
5. **조건을 매크로로 썼는지.** `{{if hp > 30}}`은 비교하지 않고 항상 참입니다. `{{if {{.hp > 30}}}}`처럼 씁니다.
6. **어디서나 쓰는 매크로인지.** `{{pipe}}`, `{{timesIndex}}`, `{{caption}}`처럼 특정 명령·기능 안에서만 값이 있는 매크로는 다른 곳에 쓰면 빈칸이 됩니다. 이런 것은 아래 [스크립트·빠른 답장 전용](#m-stscript), [기능 템플릿 전용](#m-template) 목록에 따로 모았습니다.
7. **필요한 [[확장]]이 켜져 있는지.** `{{summary}}`는 채팅 요약 확장, `{{lastExpression}}`은 캐릭터 감정 표현들 확장이 있어야 합니다.
8. **새 매크로 엔진이 켜져 있는지.** 꺼져 있으면 `{{if}}`·블록·축약이 글자 그대로 남습니다.
9. **[[이야기 문자열]] 칸인지.** 고급 서식의 그 칸은 규칙이 달라서 `{{if}}` 대신 `{{#if}}`를 써야 합니다.

### 종합 예제

캐릭터 설명 칸에 이렇게 써 두었다고 합시다. `{{description}}`은 캐릭터 카드의 설명 칸 내용으로 바뀌는 매크로입니다.

```text
{{if description}}
[설명]
{{description}}
{{/if}}
{{if {{.affection >= 50}}}}
{{char}}는 {{user}}에게 편하게 말한다.
{{else}}
{{char}}는 {{user}}에게 예의를 지키며 조심스럽게 말한다.
{{/if}}
```

한 줄씩 보면 이렇습니다.

1. `{{if description}}` — 조건 자리에 매크로 이름(`description`)을 중괄호 없이 쓰면 "그 매크로의 내용이 있는가"를 봅니다. 카드의 설명 칸에 글이 있으면 `{{/if}}`까지를 남기고, 비어 있으면 통째로 지웁니다. 설명이 없을 때 `[설명]` 제목만 덩그러니 남는 것을 막습니다.
2. `{{description}}` — 카드의 설명 칸 내용으로 바뀝니다.
3. `{{if {{.affection >= 50}}}}` — 채팅 변수 `affection`이 50 이상인지 봅니다. 안쪽 `{{.affection >= 50}}`이 먼저 `true`나 `false`로 바뀌고, 그 결과로 `if`가 고릅니다.
4. `{{else}}` 앞은 50 이상일 때, 뒤는 50 미만일 때 남는 줄입니다.

설명이 "밝고 다정한 소꿉친구."이고 `affection`이 30이면 AI에게는 이렇게 갑니다.

```result
[설명]
밝고 다정한 소꿉친구.
가나디는 챗시에게 예의를 지키며 조심스럽게 말한다.
```
