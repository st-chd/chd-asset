이 문서를 처음 보는 사람을 위한 안내입니다. 예제마다 **입력하는 글자**와 **실제로 일어나는 일**을 같이 적었습니다. `/`로 시작하는 예제는 채팅 입력창에 그대로 붙여 넣고 전송하면 실행됩니다. 예제 속 이름은 내 이름(`{{user}}`)이 챗시, 캐릭터 이름(`{{char}}`)이 가나디라고 가정합니다. 점선 밑줄이 그어진 말(예: [[프롬프트]])을 누르면 "용어 풀이"의 설명으로 갑니다.

여기서는 시작하는 데 꼭 필요한 것만 다룹니다. 변수·조건·반복처럼 그다음에 배울 것은 [매크로 문법](#macro-guide)과 [STscript 문법](#stscript)에서 차례로 설명하고, 같은 설명을 여기서 되풀이하지 않습니다.

### 매크로와 슬래시 명령

| | 매크로 | 슬래시 명령 |
|---|---|---|
| 생김새 | `{{user}}` — 중괄호 두 겹 | `/echo 안녕` — `/`로 시작 |
| 하는 일 | 그 자리의 글자를 **다른 글자로 바꿈** | **동작을 실행**(알림 띄우기, 메시지 보내기, 값 저장하기, AI 답 받기 …) |
| 쓰는 곳 | [[캐릭터 카드]], [[시스템 프롬프트]], [[월드 인포]], [[작가 노트]], 채팅 메시지, 명령 안 | 채팅 입력창, [[빠른 답장]] 버튼 |
| 처리되는 때 | 그 글이 쓰일 때마다(프롬프트를 만들 때, 메시지를 보낼 때, 명령이 실행되기 직전) | 실행할 때 한 번 |

매크로는 빈칸 채우기, 슬래시 명령은 할 일 시키기입니다. 매크로는 글자만 바꿀 뿐 동작은 하지 않습니다(값을 저장하는 몇몇 매크로만 예외이고, 매크로 문법에서 다룹니다).

캐릭터 설명에 이렇게 쓰면

```text
{{char}}는 {{user}}의 소꿉친구다.
```

AI에게는 이렇게 전달됩니다.

```result
가나디는 챗시의 소꿉친구다.
```

명령 안에 매크로를 넣으면, 명령이 실행되기 **직전에** 매크로가 먼저 글자로 바뀝니다.

```stscript
/echo {{user}}님 안녕하세요
```

1. `{{user}}`가 `챗시`로 바뀌어 `/echo 챗시님 안녕하세요`가 됩니다.
2. `/echo`가 실행되어 화면에 `챗시님 안녕하세요` [[토스트|알림]]이 잠깐 떴다 사라집니다. 채팅에는 아무것도 남지 않습니다.

### 직접 해 보기

1. 아무 채팅이나 엽니다.
2. 입력창에 `/echo 안녕`을 쓰고 전송합니다(전송 버튼을 누르거나, "Enter로 전송"이 켜져 있으면 Enter).
3. 메시지는 보내지지 않고 `안녕` 알림만 뜹니다.

- `/`로 시작하는 입력은 메시지가 아니라 명령으로 실행됩니다.
- `/`로 시작하지 않으면 평범한 메시지로 보내지고, 그 안의 매크로는 보내는 순간 바뀝니다. `{{user}}가 손을 흔든다`를 보내면 채팅에는 `챗시가 손을 흔든다`가 올라갑니다.
- 여러 줄짜리 스크립트도 입력창에 붙여 넣으면 됩니다. 컴퓨터에서 직접 칠 때 줄을 바꾸려면 Shift+Enter.
- `/`를 치면 명령 목록이, `{{`를 치면 매크로 목록이 뜹니다.

### 기호 읽는 법

이 문서에 나오는 기호를 한자리에 모았습니다. 지금 다 외울 필요는 없습니다. 읽다가 모르는 기호가 나오면 여기로 돌아와 찾아보세요. 화살표(→) 뒤의 글을 누르면 그 기호를 자세히 배우는 곳으로 갑니다.

#### 매크로에 쓰는 기호

| 기호 | 뜻 | 예 |
|---|---|---|
| `{{ }}` | 매크로 하나의 시작과 끝 | `{{user}}` |
| `::` | [[칸]] 나누기. 매크로 이름 뒤에 넘길 값을 차례로 적음 → [매크로를 쓰는 모양](#mg-shape) | `{{roll::1d20}}` |
| 이름 뒤 공백 한 칸 | `::` 대신 쓸 수 있음. 넘길 값이 **하나**일 때만 → [매크로를 쓰는 모양](#mg-shape) | `{{roll 1d20}}` |
| `{{.이름}}` `{{$이름}}` | 저장해 둔 값([[변수]])을 짧게 꺼내 쓰는 [[축약]] → [변수](#mg-var) | `{{.hp}}` |
| `{{/이름}}` | 여는 매크로와 짝을 이뤄 닫음 → [조건](#mg-if), [블록](#mg-block) | `{{if …}}…{{/if}}` |

#### 명령에 쓰는 기호

| 기호 | 뜻 | 예 |
|---|---|---|
| `/` | 슬래시 명령의 시작 | `/echo` |
| `이름=값` | 이름 있는 인자. `=` 앞뒤에 공백 없이 붙여 씀 | `title=주의` |
| 맨 뒤 글자 | 이름 없는 인자. 이름 없이 명령 맨 뒤에 그냥 씀 | `/echo 안녕`의 `안녕` |
| `"…"` | 공백이 든 값을 한 덩어리로 묶음 | `title="오늘의 운세"` |
| `|` | 다음 명령으로 넘어감. 앞 명령의 결과값도 같이 넘어감 → [여러 명령 잇기](#st-pipe) | `/echo 하나 | /echo 둘` |
| `{{pipe}}` | 앞 명령의 결과값이 들어갈 자리 → [여러 명령 잇기](#st-pipe) | `/echo 값: {{pipe}}` |
| `||` | 다음 명령으로 넘어가되 결과값을 자동으로 넣지 않음 → [여러 명령 잇기](#st-pipe) | `/echo 하나 || /echo 둘` |
| `{: … :}` | [[클로저]]. 바로 실행하지 않고 넘겨 두는 명령 묶음 → [클로저](#st-closure) | `{: /echo 안녕 :}` |
| `/:이름` | 이름 붙여 둔 클로저나 빠른 답장 버튼을 실행 → [클로저](#st-closure) | `/:greet` |
| `\` | 바로 뒤 기호를 기호가 아닌 그냥 글자로 → [기호를 글자로 쓰기](#st-escape) | `\|` → 글자 `|` |
| `// … |` | 주석(메모). 실행되지 않음. 끝의 `|`까지가 메모 → [메모](#st-comment) | `// 메모 |` |

#### 값에 쓰는 기호

| 기호 | 뜻 | 예 |
|---|---|---|
| `[ ]` | [[리스트]]. 여러 값을 순서대로 담은 것 | `["검","방패"]` — 첫 번째가 `검`, 두 번째가 `방패` |
| `{ }` | [[딕셔너리]]. 값마다 이름표를 붙여 담은 것 | `{"hp":100,"mp":30}` — 이름표 `hp`에 `100`, 이름표 `mp`에 `30` |

### 카드 읽는 법 {#g-card}

이 문서는 매크로와 명령을 하나씩 네모난 **카드**로 설명합니다. 아래는 `/echo` 명령의 실제 카드입니다. 본문의 `/echo` 카드와 똑같은 것을 그대로 옮겨 왔습니다.

%%CARD /echo%%

위 카드를 위에서부터 읽으면 이렇습니다.

| 카드에 보이는 것 | 위 카드에서는 | 뜻 |
|---|---|---|
| 맨 위 굵은 글자 | `/echo` | 명령 이름. 이대로 입력 |
| 제목 오른쪽의 테두리 상자 | (이 카드에는 없음) | 별칭. 그 이름으로 불러도 같은 명령. 예: `/setvar` 카드의 `/setchatvar` |
| 제목 아래 글 | "화면에 알림을 띄웁니다 …" | 그 명령이 하는 일 |
| 검은 상자 | `/echo 저장했습니다` … | 예제. 그대로 따라 쓸 수 있음 |
| 노란 상자 | (이 카드에는 없음) | 주의할 점 |
| 아래쪽 표의 왼쪽 칸 `title=` | `title=`, `severity=` … | 이름 있는 인자. 쓸 때는 `title=주의`처럼 `=` 바로 뒤에 값 |
| 왼쪽 칸의 `값` 동그라미 | 표의 맨 아래 줄 | 이름 없는 인자. 이름 없이 명령 맨 뒤에 그냥 씀 |
| 강조색 글자와 앞의 점 | `값` 줄 | 필수 인자. 빠뜨리면 오류 |
| 점 없는 보통 글자 | `title=` 등 나머지 줄 | 선택 인자. 필요할 때만 씀 |
| 가운데 칸 `문자열`, `숫자` … | `title=`은 문자열, `timeout=`은 숫자 | 넣을 수 있는 값의 종류(아래 "값의 종류") |
| 가운데 칸의 `= 4000` | `timeout=` 줄 | 기본값. 그 인자를 안 쓰면 이 값으로 처리 |
| 오른쪽 칸 | "알림 제목" … | 그 인자의 설명. 정해진 값 중에 골라야 하는 인자는 여기에 값 목록이 나옴 |

카드에 동그라미가 `값` 하나가 아니라 `1`, `2`로 나오면 이름 없는 인자가 여러 개라는 뜻입니다. 그 순서대로 공백을 두고 씁니다.

이 카드를 보고 명령을 만들면 이렇습니다.

```stscript
/echo 저장했습니다
```

필수인 `값`만 썼습니다. 나머지는 기본값대로 처리되어 보통 모양(`severity=info`) 알림이 4초(`timeout=4000`) 동안 뜹니다.

```stscript
/echo severity=warning timeout=10000 title=주의 체력이 얼마 남지 않았습니다
```

| 부분 | 뜻 |
|---|---|
| `severity=warning` | 정해진 값 중 하나를 고른 것. 경고 모양 알림 |
| `timeout=10000` | 숫자. 단위가 1000분의 1초라서 10초 |
| `title=주의` | 알림 제목 |
| `체력이 얼마 남지 않았습니다` | 이름 없는 인자. 알림 본문 |

이름 있는 인자는 **반드시 이름 없는 인자보다 앞에** 씁니다. `/echo 안녕 title=인사`라고 쓰면 `title=인사`까지 본문 글자가 됩니다.

#### 매크로 카드

매크로 카드도 생김새가 같습니다. 아래는 주사위를 굴리는 `{{roll}}` 매크로의 실제 카드입니다.

%%CARD {{roll}}%%

매크로 카드의 제목은 쓰는 모양 그대로입니다. 단, 제목 안의 영어 단어(`formula` 등)는 **그 자리에 넣을 것의 이름**이지 그대로 쓰는 글자가 아닙니다. `{{roll::formula}}`라고 쓰는 것이 아니라 `formula` 자리에 주사위 식을 넣어 `{{roll::2d6+3}}`처럼 씁니다.

| 카드 제목 | 실제로 쓰는 예 | 결과 |
|---|---|---|
| `{{user}}` | `{{user}}` | `챗시` |
| `{{roll::formula}}` | `{{roll::2d6+3}}` | 6면 주사위 2개를 굴려 합친 뒤 3을 더함. 결과값은 5~15 중 하나 |
| `{{space::[count]}}` | `{{space}}`, `{{space::3}}` | 공백 1개, 공백 3개 |
| `{{random::항목1::항목2::…}}` | `{{random::맑음::흐림::비}}` | 셋 중 하나 |
| `{{time::[UTC±N]}}` | `{{time}}`, `{{time::UTC+9}}` | 지금 시각, 한국 시각 |

- `[ ]`로 감싼 칸은 생략해도 됩니다. 생략하면 그 칸의 기본값(`= 1` 등)이 쓰입니다.
- 카드 아래쪽 표는 칸 순서대로 이름·종류·설명입니다. 강조색은 꼭 채워야 하는 칸입니다.
- 제목 오른쪽 별칭 중 점선 테두리는 자동완성 목록에는 안 뜨지만 똑같이 동작하는 이름입니다.

### 값의 종류

카드 가운데 칸에 적힌 이름의 뜻입니다. 처음에는 위의 넷만 알면 됩니다.

| 카드 표기 | 뜻 | 예 |
|---|---|---|
| 문자열 | 글자. 대부분의 값이 이것 | `안녕`, `"공백 있는 글"` |
| 숫자 | 숫자. 음수·소수도 됨 | `10`, `-3`, `0.5` |
| 불리언 | [[참과 거짓|참·거짓]] 둘 중 하나를 나타내는 값. "켠다/끈다", "맞다/아니다"를 정할 때 씀 | 참: `true` `on` `1` / 거짓: `false` `off` `0` |
| 끝에 `…` | 같은 종류를 여러 개 이어 써도 됨 | |
| 리스트 | 여러 값을 순서대로 담은 것. `[ ]` 안에 쉼표로 구분, 글자는 큰따옴표 | `["검","방패"]` |
| 딕셔너리 | 값마다 이름표를 붙여 담은 것. `{ }` 안에 `"이름표":값` | `{"hp":100,"mp":30}` |
| 변수 이름 | 값을 넣어 둔 [[변수]]의 **이름**. [STscript의 변수](#st-var)에서 배움 | `hp` |
| 클로저 | 바로 실행하지 않고 넘겨 두는 명령 묶음. [클로저](#st-closure)에서 배움 | `{: /echo 안녕 :}` |
| 명령 | 따옴표로 감싼 명령 한 줄. 클로저가 생기기 전의 옛 방식 | `"/echo 안녕"` |
| 범위 | 메시지 번호 `시작-끝`. 양 끝 포함 | `3-5`(3, 4, 5번), `7`(7번 하나) |

### 자주 하는 실수

| 틀린 예 | 고친 예 | 이유 |
|---|---|---|
| `{{user}`, `{user}}`, `{[user}]` | `{{user}}` | 중괄호 `{ }`만, 양쪽에 두 겹씩. 옆 글쇠의 `[ ]`가 섞이기 쉬움 |
| `/echo title:인사 안녕` | `/echo title=인사 안녕` | 이름 있는 인자는 `:`가 아니라 `=` |
| `/echo title = 인사 안녕` | `/echo title=인사 안녕` | `=` 앞뒤에 공백 없이 |
| `/echo 안녕 title=인사` | `/echo title=인사 안녕` | 이름 있는 인자는 앞에 |
| `/echo title=오늘의 운세 대길` | `/echo title="오늘의 운세" 대길` | 공백이 든 값은 따옴표로 |
| `{{random:맑음:흐림}}` | `{{random::맑음::흐림}}` | 매크로의 칸 나누기는 `::` |

변수·조건·주석에서 자주 틀리는 것은 그것을 배우는 [STscript 문법의 "자주 하는 실수"](#st-mistakes)와 [매크로가 안 바뀌거나 빈칸이 될 때](#mg-trouble)에 모았습니다.
