# 영어 원문 ⇒ 한국어 (인자 설명·선택지 설명 공용 사전)
Suppress toast message notifications. ⇒ 알림을 띄우지 않음
If true, does not alter quoted literal unnamed arguments ⇒ 이름 없는 인자을 큰따옴표로 감쌌을 때 따옴표를 어떻게 할지. `true`(기본)면 따옴표까지 그대로 쓰고, `false`면 바깥 따옴표를 떼어 냄. 예: `/echo raw=false "안녕"`은 알림 `안녕`
The way how you want the return value to be provided ⇒ 결과를 어디로 보낼지. 아래 목록 중 하나
The way to return the result ⇒ 결과를 어디로 보낼지. 아래 목록 중 하나
Character name - or unique character identifier (avatar key) ⇒ 캐릭터 이름, 또는 캐릭터를 정확히 가리키는 아바타 파일 이름(예: `끼끼.png`)
Character name or avatar key. If not provided, uses the currently selected character. ⇒ 캐릭터 이름 또는 아바타 파일 이름. 비우면 지금 캐릭터
Persona name or avatar key. If not provided, uses the currently active persona. ⇒ 페르소나 이름 또는 아바타 파일 이름. 비우면 지금 페르소나
Suppress the toast message on template change ⇒ 바꿀 때 뜨는 알림을 숨김
lock user input during generation ⇒ AI가 답을 쓰는 동안 입력창을 잠금
API response length in tokens ⇒ 이번에만 쓸 최대 답 길이(토큰). 비우면 설정값
change the type of the value when used with index ⇒ `index=`와 함께 쓸 때 넣을 값의 종류. 예: `as=number`면 글자 `"5"`가 아니라 숫자 `5`로 저장
lorebook name if creating a new one, will be auto-generated otherwise ⇒ 로어북을 새로 만들게 될 때 쓸 이름. 비우면 자동
create a new lorebook if it doesn't exist ⇒ 연결된 로어북이 없으면 새로 만들어 연결할지
Message ID or range (e.g. 0-10). If not provided, the last message is used. ⇒ 메시지 번호 또는 `시작-끝` 범위(예: `0-10`). 비우면 마지막 메시지
Two character language code according to IETF BCP 47 ⇒ 두 글자 언어 코드(`ko` 한국어, `en` 영어, `ja` 일본어 등). 언어마다 단어·문장을 나누는 규칙이 다름
numeric ID of the QR, e.g., id=42 ⇒ 버튼 번호(예: `id=42`). 같은 글자의 버튼이 여럿일 때 정확히 고르는 용도
name of the QR set, e.g., set=PresetName1 ⇒ 빠른 답장 세트 이름(예: `set=전투버튼`)
text on the button, e.g., label=MyButton ⇒ 버튼에 보이는 글자(예: `label=공격`)
the label of the quick reply ⇒ 빠른 답장 버튼 글자
QR set name ⇒ 빠른 답장 세트 이름
Extension name ⇒ 확장 이름. 확장 메뉴에 보이는 이름이나 폴더 이름(예: `SillyTavern-LALib`)
named arguments assigned to scoped variables to be used in the expression ⇒ 식 안에서 쓸 임시 값. `이름=값`으로 여러 개 넘길 수 있음. 예: `answer={{pipe}}`
the list or dictionary to iterate over ⇒ 하나씩 돌아볼 리스트나 딕셔너리(직접 쓰거나 `{{var::x}}`로 넘김)
position to insert the message (index-based, corresponding to message id). If not set, the message will be inserted at the end of the chat.
Negative values (including -0) are accepted and will work similarly to how 'depth' usually works. For example, -1 will insert the message right before the last message in chat. ⇒ 메시지를 끼워 넣을 위치(메시지 ID 기준, 0부터). 생략하면 채팅 맨 끝에 추가합니다. 음수도 받으며 depth처럼 뒤에서 셉니다. `-1`은 마지막 메시지 바로 앞, `-0`은 맨 끝입니다.
