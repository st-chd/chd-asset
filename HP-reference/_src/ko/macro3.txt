@setvar
[[채팅 변수]]에 값을 **저장**합니다. 값은 변수 안에 들어가고, 매크로를 쓴 자리에는 아무 글자도 남지 않습니다.
```text
{{setvar::hp::100}}{{char}}의 체력은 {{getvar::hp}}이다.
```
1. `{{setvar::hp::100}}` — `hp`라는 이름의 변수에 `100`을 넣습니다. 글에는 아무것도 남기지 않습니다.
2. `{{getvar::hp}}` — 방금 넣은 `100`을 꺼내 그 자리에 넣습니다.
```result
가나디의 체력은 100이다.
```
이미 `hp`에 값이 있었다면 새 값으로 덮어씁니다. 긴 글은 [[블록]]으로 넣을 수 있습니다: `{{setvar::메모}}여러 줄 글{{/setvar}}`.
! 카드·프롬프트에 넣으면 AI에게 답을 받을 때마다(스와이프 포함) **또** 실행됩니다. 위 예를 캐릭터 설명에 두면 체력을 아무리 바꿔 놔도 답을 받을 때마다 100으로 돌아갑니다. "처음 한 번만" 넣고 싶은 값은 [[슬래시 명령]] `/setvar`로 넣거나, 축약 `{{.hp ??= 100}}`을 쓰세요. `??=`는 "변수가 **아직 없을 때만** 저장하라"는 기호이고, 아래 "변수 축약 문법"의 `{{.이름 ?? 기본값}}` 카드에서 설명합니다.

#1 넣을 값

@addvar
채팅 변수에 값을 **더합니다**. 더한 결과는 변수 안에 들어가고, 매크로를 쓴 자리에는 아무 글자도 남지 않습니다. 지금 들어 있는 값에 따라 하는 일이 다릅니다.
| 지금 값 | 더하는 값 | 결과 |
|---|---|---|
| (없음) | `5` | `5` (0에서 시작) |
| `10` | `5` | `15` |
| `10` | `-3` | `7` (빼기는 음수를 더함) |
| `안녕` | `하세요` | `안녕하세요` (글자 이어 붙이기) |
| `["검"]` | `방패` | `["검","방패"]` ([[리스트]]에 추가) |
```text
{{addvar::gold::50}}{{user}}의 금화: {{getvar::gold}}
```
`gold`가 100이었다면:
```result
챗시의 금화: 150
```
! 카드·프롬프트에 넣으면 답을 받을 때마다 또 더해집니다. 위 예를 카드에 두면 답을 받을 때마다 금화가 50씩 늘어납니다.
#0 변수 이름
#1 더할 값

@incvar
채팅 변수를 **1 늘리고**, 늘어난 값으로 바뀝니다. 변수가 없으면 0에서 시작해 `1`이 됩니다.
```text
{{char}}의 {{incvar::방문}}번째 방문.
```
`방문`이 2였다면:
```result
가나디의 3번째 방문.
```
`{{setvar}}`·`{{addvar}}`는 자리에 아무 글자도 남기지 않지만, 이 매크로는 늘어난 값이 그 자리에 **들어갑니다**.
! 카드·프롬프트에 넣으면 답을 받을 때마다 1씩 늘어납니다. 스와이프를 세 번 하면 세 번 늘어납니다.
#0 변수 이름

@decvar
채팅 변수를 **1 줄이고**, 줄어든 값으로 바뀝니다. `{{incvar}}`의 반대입니다.
```text
남은 기회: {{decvar::기회}}
```
`기회`가 3이었다면 `남은 기회: 2`.
#0 변수 이름

@getvar
채팅 변수에 들어 있는 값을 꺼내 그 자리에 넣습니다. `{{setvar}}`나 `/setvar` 명령으로 값을 저장한 적이 없는 변수면 빈칸입니다.
```text
{{char}}의 기분: {{getvar::mood}}
```
`mood`에 `설렘`이 들어 있으면:
```result
가나디의 기분: 설렘
```
변수 이름이 영어면 줄여서 `{{.mood}}`로 써도 똑같습니다([[축약]]).
#0 변수 이름

@hasvar
채팅 변수가 **있으면** `true`, 없으면 `false`로 바뀝니다. 값이 `0`이나 빈칸이어도 저장한 적이 있으면 `true`입니다. 별칭 `{{varexists}}`도 같습니다.
```text
{{if {{hasvar::이름}}}}이미 이름을 정했다.{{else}}아직 이름이 없다.{{/if}}
```
값이 참인지가 아니라 "저장한 적이 있는지"를 보고 싶을 때 씁니다.
#0 변수 이름

@deletevar
채팅 변수를 **지웁니다**. 매크로를 쓴 자리에는 아무 글자도 남지 않습니다. 지운 뒤에는 `{{hasvar}}`가 `false`가 됩니다. 별칭 `{{flushvar}}`도 같습니다.
```text
{{deletevar::임시}}
```
#0 변수 이름

@setvarkey
채팅 변수에 든 [[리스트]]나 [[딕셔너리]]의 **한 칸만** 바꿉니다. 매크로를 쓴 자리에는 아무 글자도 남지 않습니다. 별칭 `{{setvarindex}}`도 같습니다.
```text
{{setvarkey::stat::hp::80}}
{{setvarkey::bag::0::낡은 검}}
```
1. `stat`이 `{"hp":100,"mp":30}`이었다면 `hp` 칸만 바뀌어 `{"hp":"80","mp":30}`이 됩니다.
2. `bag`이 `["검","방패"]`였다면 0번(첫 번째) 칸이 바뀌어 `["낡은 검","방패"]`가 됩니다.
변수가 없으면 새로 만듭니다. 둘째 칸이 숫자면 리스트, 글자면 딕셔너리로 만듭니다.
! `a.b`처럼 점으로 더 깊은 칸을 가리키는 쓰기는 안 됩니다. `a.b`라는 이름표 하나로 처리됩니다.
#0 변수 이름
#1 바꿀 칸. 딕셔너리면 이름표, 리스트면 번호([[인덱스]], 0부터)
#2 넣을 값

@getvarkey
채팅 변수에 든 리스트·딕셔너리의 **한 칸만** 꺼냅니다. 별칭 `{{getvarindex}}`도 같습니다.
```text
체력 {{getvarkey::stat::hp}}, 첫 물건 {{getvarkey::bag::0}}
```
`stat`이 `{"hp":100,"mp":30}`, `bag`이 `["검","방패"]`라면:
```result
체력 100, 첫 물건 검
```
#0 변수 이름
#1 꺼낼 칸. 딕셔너리면 이름표, 리스트면 번호(0부터)

@setglobalvar
[[전역 변수]]에 값을 저장합니다. `{{setvar}}`의 전역 변수판입니다. 쓰는 법은 같고 저장되는 곳만 다릅니다. 전역 변수는 모든 채팅·모든 캐릭터에서 함께 보입니다.
```text
{{setglobalvar::season::겨울}}
```
이제 어느 채팅에서든 `{{getglobalvar::season}}`이나 `{{$season}}`이 `겨울`로 바뀝니다.
! 같은 이름의 채팅 변수와는 서로 다른 칸입니다. `{{setglobalvar::hp::5}}`를 해도 `{{getvar::hp}}`는 바뀌지 않습니다.
#0 변수 이름
#1 넣을 값

@addglobalvar
전역 변수에 값을 더합니다. `{{addvar}}`의 전역 변수판입니다(숫자는 더하기, 글자는 이어 붙이기, 리스트는 추가).
```text
{{addglobalvar::totalTurns::1}}
```
전역 변수 `totalTurns`가 7이었다면 8이 됩니다. 매크로를 쓴 자리에는 아무 글자도 남지 않습니다.
#0 변수 이름
#1 더할 값

@incglobalvar
전역 변수를 1 늘리고 늘어난 값으로 바뀝니다. `{{incvar}}`의 전역 변수판입니다.
#0 변수 이름

@decglobalvar
전역 변수를 1 줄이고 줄어든 값으로 바뀝니다. `{{decvar}}`의 전역 변수판입니다.
#0 변수 이름

@getglobalvar
전역 변수에 든 값을 꺼내 그 자리에 넣습니다. `{{getvar}}`의 전역 변수판입니다. 값을 저장한 적이 없는 변수면 빈칸입니다. 변수 이름이 영어면 `{{$이름}}`으로 줄여 쓸 수 있습니다.
```text
지금 계절: {{getglobalvar::season}}
```
```result
지금 계절: 겨울
```
#0 변수 이름

@hasglobalvar
전역 변수가 있으면 `true`, 없으면 `false`로 바뀝니다. `{{hasvar}}`의 전역 변수판입니다. 별칭 `{{globalvarexists}}`도 같습니다.
#0 변수 이름

@deleteglobalvar
전역 변수를 지웁니다. `{{deletevar}}`의 전역 변수판입니다. 별칭 `{{flushglobalvar}}`도 같습니다.
