/db-disable 설정집.txt

@caption
그림을 보고 AI가 **설명 글**(캡션)을 써서 결과로 남깁니다. 이미지 캡셔닝 [[확장]]을 씁니다. 기본으로는 파일 선택 창이 뜨고, 만든 설명을 채팅 메시지로도 보냅니다.
```stscript
/caption quiet=true mesId={{lastMessageId}} | /echo
```
마지막 메시지에 붙은 그림의 설명을 채팅에 보내지 않고 알림으로만 띄웁니다.
.quiet 만든 설명을 채팅에 보내지 않음
.mesId 파일을 고르는 대신 이 번호 메시지에 붙은 그림을 씀
.index 그 메시지에 그림이 여러 장이면 몇 번째(0부터)를 쓸지

@qr-create
[[빠른 답장]] 세트에 **새 버튼**을 만듭니다. 자동 실행 칸(`startup`~`generation`)을 켜면 그때마다 이 버튼이 저절로 실행됩니다.
```stscript
/qr-create set=전투버튼 label=주사위 /echo \{\{roll::1d20\}\}
```
`전투버튼` 세트에 `주사위` 버튼이 생기고, 누를 때마다 1~20 숫자가 알림으로 뜹니다.
! 내용에 매크로를 그냥 `{{roll::1d20}}`으로 쓰면 이 명령이 실행되는 순간 숫자로 바뀌어, 버튼에는 `/echo 14`처럼 고정된 숫자가 저장됩니다. 버튼을 누를 때 바뀌게 하려면 위처럼 중괄호 앞에 `\`를 붙입니다([[이스케이프]]).
```stscript
/qr-create set=자동 label=턴세기 hidden=true bot=true /incvar turn
```
화면에 안 보이는 버튼을 만들고, AI 답이 올 때마다 저절로 `turn`을 1 늘립니다.
.set 버튼을 만들 세트 이름
.label 버튼 글자
.icon 버튼 아이콘(Font Awesome 이름, 예: `fa-dice`)
.showlabel 아이콘이 있어도 글자를 같이 보임
.hidden 버튼을 화면에 숨김(다른 버튼이나 자동 실행으로만 부름)
.startup 앱을 켤 때 저절로 실행
.user 내가 메시지를 보낼 때 저절로 실행
.bot AI 답이 올 때 저절로 실행

.group 그룹에서 답할 캐릭터가 정해질 때 저절로 실행
.generation AI 답을 받기 직전에 저절로 실행
.title 버튼에 마우스를 올리면 뜨는 설명

#0 지울 버튼 글자(`label=` 대신)

@qr-contextadd
[[빠른 답장]] 버튼에 **오른쪽 클릭 메뉴**를 붙입니다. 메뉴에는 다른 세트의 버튼들이 나옵니다.
```stscript
/qr-contextadd set=전투버튼 label=공격 공격기술
```
`공격` 버튼을 오른쪽 클릭하면 `공격기술` 세트의 버튼들이 메뉴로 나옵니다.
.set 메뉴를 붙일 버튼이 있는 세트
.label 메뉴를 붙일 버튼 글자
.id 메뉴를 붙일 버튼 번호(`label=`보다 우선)
.chain `true`면 메뉴 항목을 누를 때 원래 버튼을 먼저 실행하고 이어서 메뉴 항목을 실행
#0 메뉴로 붙일 세트 이름

@qr-contextdel
[[빠른 답장]] 버튼의 오른쪽 클릭 메뉴에서 세트 하나를 뗍니다.
```stscript
/qr-contextdel set=전투버튼 label=공격 공격기술
```
.set 버튼이 있는 세트
.label 버튼 글자
.id 버튼 번호(`label=`보다 우선)
