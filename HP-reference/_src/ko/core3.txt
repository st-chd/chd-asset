@buttons
버튼 여러 개가 있는 [[팝업|창]]을 띄우고, **누른 버튼의 글자**를 결과로 남깁니다. 창을 그냥 닫으면 빈 값입니다.
```stscript
/buttons labels=["공격","방어","도망"] 어떻게 할까? |
/echo {{pipe}}를 골랐다
```
`방어`를 누르면 알림 `방어를 골랐다`.
```stscript
/buttons multiple=true labels=["검","방패","포션"] 가져갈 것을 모두 고르세요
```
`multiple=true`면 버튼을 여러 개 눌러 켜 둘 수 있고, 고른 것들이 `["검","포션"]` 같은 [[리스트]]로 결과가 됩니다.
버튼에 아이콘과 설명을 붙이려면 [[딕셔너리]]로 씁니다: `labels=[{"text":"저장","icon":"fa-floppy-disk","tooltip":"바꾼 내용 저장"},{"text":"취소"}]`. `icon`은 Font Awesome 아이콘 이름입니다.
.labels 버튼 목록. `["글자1","글자2"]` 모양, 또는 `text`·`tooltip`·`icon`이 든 딕셔너리 목록
.multiple `true`면 여러 개를 골라 리스트로 돌려줌
#0 창에 보일 안내

@trimtokens
글을 정한 [[토큰]] 수만큼만 남기고 자릅니다. 앞부분을 남길지 뒷부분을 남길지 고릅니다. 토큰은 지금 설정된 토크나이저(토큰 세는 방식)로 셉니다.
```stscript
/trimtokens limit=50 direction=end {{lastMessage}}
```
마지막 메시지에서 **뒤쪽** 50토큰만 남긴 글을 결과로 남깁니다. 긴 글을 요약 지시에 넣기 전에 길이를 줄일 때 씁니다.
.limit 남길 토큰 수
.direction 어느 쪽을 남길지. `start` = 앞부분, `end` = 뒷부분

@inject
채팅 화면에는 보이지 않게, AI에게 보내는 프롬프트에 글을 **끼워 넣습니다**([[주입]]). 한 번 넣으면 지울 때까지 매번 들어갑니다(채팅에 같이 저장됨). 주입 ID를 결과로 남깁니다.
```stscript
/inject id=weather position=chat depth=1 [지금 바깥에는 비가 내린다.]
```
| 부분 | 뜻 |
|---|---|
| `id=weather` | 이 주입의 이름. 나중에 바꾸거나 지울 때 씀 |
| `position=chat` | 채팅 기록 사이에 넣음 |
| `depth=1` | 이 글 아래에 메시지를 1개 남김. 곧 마지막 메시지 바로 위 |
| `[지금 바깥에는 비가 내린다.]` | 넣을 글 |
- 같은 `id`로 다시 실행하면 내용이 바뀝니다.
- 글 없이 `/inject id=weather`만 실행하면 그 주입이 지워집니다. 같은 이름을 빈 내용으로 덮어쓰는 셈이라 넣을 글이 없어지기 때문입니다.
- `ephemeral=true`를 붙이면 다음 답을 한 번 받은 뒤 저절로 지워집니다.
.id 주입 이름. 비우면 자동으로 붙음
.position 넣을 위치
=before 메인 프롬프트(시스템 프롬프트 등) 앞
=after 메인 프롬프트 뒤(기본)
=chat 채팅 기록 사이. 자리는 `depth=`로
=none 프롬프트에 넣지 않음. `scan=true`와 함께 월드 인포 키워드만 건드릴 때 씀
.depth `position=chat`일 때 넣을 [[깊이]](이 글 아래에 남길 메시지 개수). `0` = 마지막 메시지 아래, `1` = 마지막 메시지 바로 위. 기본 `4`
.scan 넣은 글도 [[월드 인포]] 키워드 검사에 포함. 이 글에 키워드가 있으면 그 항목이 켜짐
.role `position=chat`일 때 누구의 말로 넣을지. 기본 `system`
.ephemeral 다음 답을 받은 뒤 저절로 지움(한 번만 쓰기)
.filter 이 [[클로저]]가 `true`를 돌려줄 때만 넣음. 답을 받을 때마다 검사

@getpromptentry
[[Text Completion|Chat Completion]]의 프롬프트 관리자 목록에서, 항목이 켜져 있는지(`true`) 꺼져 있는지(`false`)를 결과로 남깁니다.

```
.identifier 항목의 내부 이름(예: `main`, `jailbreak`, `chatHistory`, 직접 만든 항목은 긴 ID). 여러 개 가능

@setpromptentry

```
첫 줄은 `Jailbreak` 항목을 끄고, 둘째 줄은 `main` 항목을 켜져 있으면 끄고 꺼져 있으면 켭니다.
.identifier 바꿀 항목의 내부 이름. 여러 개 가능
.name 바꿀 항목의 화면 이름. 여러 개 가능

@api-url
[[API]] 서버 **주소**를 바꿉니다(포트 번호까지). 주소 없이 쓰면 지금 주소를 결과로 남깁니다. 내 컴퓨터에서 돌리는 AI 프로그램(KoboldCpp 등)에 연결할 때 씁니다.
```stscript

```
첫 줄은 지금 API의 주소를 바꾸고 바로 연결합니다. 둘째 줄은 지금 쓰지 않는 `koboldcpp`의 주소만 바꿔 둡니다.
! 대부분의 Text Completion 프로그램과, Chat Completion 중 Custom(OpenAI 호환)·Z.AI·SiliconFlow·MiniMax·Pollinations·Vertex AI에서만 됩니다.
! 지금 고르지 않은 API의 주소를 바꿀 때는 `connect=false`를 함께 씁니다. 바로 연결은 지금 API에서만 됩니다.
.api 주소를 바꿀 API. 비우면 지금 API
.connect 바꾼 뒤 바로 연결할지
.quiet 알림을 숨김

#0 바꿀 글

@substr
글의 **일부분**을 잘라 냅니다. 몇 번째 글자부터(`start=`) 몇 번째 글자 앞까지(`end=`)를 남깁니다. 번호는 0부터, 음수는 뒤에서부터 셉니다.
```stscript
/substr start=0 end=2 안녕하세요 | /echo
/substr start=-3 안녕하세요 | /echo
```
| 줄 | 결과 | 이유 |
|---|---|---|
| 1 | `안녕` | 0번(`안`)부터 2번(`하`) **앞**까지 |
| 2 | `하세요` | 뒤에서 3번째 글자부터 끝까지 |
- `start=`를 비우면 처음부터, `end=`를 비우면 끝까지입니다.
- `end=` 위치의 글자 자체는 들어가지 않습니다.
- 범위가 맞지 않으면(시작이 끝보다 뒤 등) 빈 값입니다.
.start 시작 위치(이 글자부터 포함). 0부터, 음수는 뒤에서
.end 끝 위치(이 글자 앞까지). 음수는 뒤에서

@replace
글 안에서 찾은 부분을 다른 글로 **바꿉니다**. `replacer=`를 비우면 찾은 부분을 지웁니다. 다른 이름 `/re`.
```stscript
/replace pattern=사과 replacer=배 사과 두 개와 사과 주스 | /echo
```
알림 `배 두 개와 배 주스`. 기본 방식은 찾은 것을 **모두** 바꿉니다.
```stscript
/replace mode=regex pattern="/[0-9]+/g" replacer=○ 3월 14일 | /echo
```
[[정규식]] 방식입니다. 숫자 묶음을 모두 `○`로 바꿔 알림 `○월 ○일`. 정규식은 끝에 `g`를 붙여야 모두 바꾸고, 없으면 첫 번째만 바꿉니다.
.mode 찾는 방식
=literal 쓴 글자 그대로 찾음(대소문자 구분, 전부 바꿈)
=regex `/식/옵션` 모양의 정규식으로 찾음
.pattern 찾을 글 또는 정규식
.replacer 바꿔 넣을 글. 정규식 방식에서는 `$1`로 괄호 부분을 가져올 수 있음
#0 원래 글

@match
[[정규식]]으로 글에서 맞는 부분을 찾아, 찾은 것들을 [[리스트]]로 결과에 남깁니다.
```stscript
/match pattern="/(\d+)시/" 오후 3시에 만나 | /echo
```
알림 `["3시","3"]`. 첫 칸은 맞은 부분 전체, 다음 칸들은 괄호 `( )`로 묶은 부분입니다.
- 정규식 끝에 `g`가 있으면 맞는 곳마다 리스트를 하나씩 만들어 리스트 안에 리스트로 돌려줍니다.
- 맞는 게 없으면 `g`가 있을 때 `[]`, 없을 때 빈 값입니다.
.pattern 찾을 정규식. `/식/옵션` 모양이 아니면 쓴 글 전체를 정규식으로 봄
