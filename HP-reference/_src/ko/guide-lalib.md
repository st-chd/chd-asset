## LALib와 식(계산식)

LALib는 [[STscript]]에 명령을 100개 가까이 더해 주는 [[확장]]입니다(만든 사람 LenAnderson, 이 문서는 3.12.1 기준). 이 확장이 설치되어 켜져 있어야 아래 명령들을 쓸 수 있습니다. 확장 메뉴에 "LALib"가 보이면 설치된 것입니다.

LALib 명령도 보통 슬래시 명령과 쓰는 법이 같습니다. [STscript 문법](#stscript)에서 배운 `|`, 변수, 클로저를 그대로 씁니다. 새로 배울 것은 **식** 하나입니다.

식은 `1 + 2`, `hp > 50`처럼 계산이나 비교를 수학 시간에 쓰던 모양 그대로 적은 것입니다. SillyTavern 기본 `/if`는 비교를 `left=`·`rule=`·`right=` 셋으로 나눠 써야 하지만, LALib의 `/ife`는 식을 그대로 받습니다.

```stscript
/if left=hp rule=gt right=50 {: /echo 많다 :}
```

```stscript
/ife (hp > 50) {: /echo 많다 :}
```

두 스크립트는 같은 일을 합니다. 변수 `hp`가 50보다 크면 알림 `많다`가 뜹니다. 아래가 LALib 방식입니다.

식을 쓰는 곳은 두 가지입니다.

- **계산해서 결과값으로 남길 때**: `/=` 명령 뒤에 식을 씁니다.
- **참인지 거짓인지 물을 때**: 식을 받는 명령(`/ife`, `/elseif`, `/whilee`, `/filter`, `/find` 등)에 괄호로 감싸 넘깁니다. 예: `/ife (hp > 50) {: … :}`.

```stscript
/= 1 + 2 * 3 |
/echo
```

1. `/=`가 식 `1 + 2 * 3`을 계산합니다. 곱하기를 먼저 하므로 `7`입니다. 이 `7`이 결과값으로 남습니다.
2. `/echo`는 띄울 글이 비어 있으므로 앞 결과값 `7`이 들어가 알림 `7`이 뜹니다.

아래 예제들은 모두 이 모양(`/= 식 | /echo`)으로 식의 결과를 알림으로 확인합니다.

### 식에 쓰는 값

| 종류 | 쓰는 법 | 예 | 결과 |
|---|---|---|---|
| 숫자 | 그대로. 소수점은 `.` | `/= -1.5` | `-1.5` |
| 글자 | **작은따옴표**로 감쌈 | `/= '안녕'` | `안녕` |
| 참·거짓 | `true`, `false` | `/= true` | `true` |
| 변수 | 이름만 씀 | `/let x 5 | /= x` | `5` |
| 매크로 | 중괄호 **한 겹** | `/= {char}` | `가나디` |

- 식 안에서 **글자는 작은따옴표** `'…'`로 감쌉니다. 큰따옴표가 아닙니다. 따옴표 없이 `안녕`이라고 쓰면 글자가 아니라 `안녕`이라는 이름의 **변수**를 찾습니다.
- 변수 이름을 쓰면 [[범위 변수]] → [[채팅 변수]] → [[전역 변수]] 순서로 찾습니다. 같은 이름이 여럿이면 먼저 찾은 것을 씁니다.
- 표의 `/let x 5`는 "`x`라는 범위 변수를 만들고 `5`를 넣어라"입니다. `/let`은 `이름=값`이 아니라 띄어쓰기로 이름과 값을 나란히 씁니다.
- 식 안에서 매크로는 중괄호 **한 겹**(`{char}`)으로 씁니다. 두 겹(`{{char}}`)으로 쓰면 식이 시작되기 전에 먼저 `가나디`라는 따옴표 없는 글자로 바뀌어 버려서, 식은 `가나디`라는 변수를 찾게 됩니다.

### 계산

| 식 | 뜻 | 예 → 결과 |
|---|---|---|
| `a + b` | 더하기 | `1 + 1` → `2` |
| `a - b` | 빼기 | `10 - 1` → `9` |
| `a * b` | 곱하기 | `2 * 5` → `10` |
| `a / b` | 나누기 | `7 / 2` → `3.5` |
| `a // b` | 나누고 소수점 아래 버리기 | `7 // 2` → `3` |
| `a % b` | 나눈 나머지 | `7 % 2` → `1` |
| `a ** b` | 거듭제곱 | `2 ** 3` → `8` (2를 세 번 곱함) |

```stscript
/setvar key=gold 120 |
/= gold // 50 |
/echo 50골드짜리 물건을 {{pipe}}개 살 수 있다
```

`gold`가 120이므로 `120 // 50`은 `2`. 알림 `50골드짜리 물건을 2개 살 수 있다`.

### 비교

비교식의 결과는 `true`(맞다)나 `false`(틀리다)입니다.

| 식 | 뜻 | 예 → 결과 |
|---|---|---|
| `a == b` | 같다 | `1 == '1'` → `true` |
| `a != b` | 다르다 | `1 != 2` → `true` |
| `a === b` | 종류까지 같다 | `1 === '1'` → `false` (숫자 1과 글자 1은 종류가 다름) |
| `a !== b` | 종류까지 따지면 다르다 | `1 !== '1'` → `true` |
| `a > b`, `a >= b` | 크다, 크거나 같다 | `3 >= 3` → `true` |
| `a < b`, `a <= b` | 작다, 작거나 같다 | `2 < 1` → `false` |
| `a in b` | a가 b 안에 들어 있다 | `'하세' in '안녕하세요'` → `true`, `2 in [1,2,3]` → `true` |
| `a not in b` | a가 b 안에 없다 | `4 not in [1,2,3]` → `true` |
| `a <=> b` | a가 크면 `1`, 같으면 `0`, 작으면 `-1` | `10 <=> 20` → `-1` (정렬할 때 씀) |

`==`는 느슨하게 비교해서 `0 == ''`(숫자 0과 빈 글자)도 `true`입니다. 정확히 비교하려면 `===`를 쓰세요.

```stscript
/setvar key=hp 30 |
/ife (hp <= 50) {: /echo 체력이 절반 이하다 :}
```

`hp`가 30이라 `30 <= 50`은 `true`. 알림 `체력이 절반 이하다`가 뜹니다. `hp`가 80이었다면 `false`라서 아무것도 뜨지 않습니다.

### 뒤집기: `!`

`!`를 앞에 붙이면 참과 거짓이 뒤바뀝니다.

| 식 | 결과 |
|---|---|
| `!true` | `false` |
| `!false` | `true` |
| `!(hp > 50)` | `hp`가 50보다 크지 **않으면** `true` |

### 둘 이상 묶기: `and`, `or`, `xor`

| 연산자 | 뜻 | `true and false`처럼 썼을 때 |
|---|---|---|
| `and` | 둘 다 맞아야 `true` | `true and false` → `false` |
| `or` | 하나라도 맞으면 `true` | `true or false` → `true` |
| `xor` | 딱 하나만 맞아야 `true` | `true xor false` → `true`, `true xor true` → `false` |

`and`를 `or`보다 먼저 계산합니다. 헷갈리면 괄호로 묶으세요.

```stscript
/ife (hp > 50 and (hasKey or isOpen)) {: /echo 문을 연다 :}
```

`hp`가 50보다 크고, **그리고** `hasKey`와 `isOpen` 중 하나라도 참이면 알림 `문을 연다`가 뜹니다. 조건이 안 맞으면 아무것도 뜨지 않습니다.

### 종류 확인: `is`

값이 어떤 종류인지 묻습니다. 그 종류가 맞으면 `true`, 아니면 `false`가 결과입니다.

| 식 | `true`가 되는 때 | 예 → 결과 |
|---|---|---|
| `x is string` | 글자일 때 | `'안녕' is string` → `true` |
| `x is number` | 숫자일 때 | `'안녕' is number` → `false` |
| `x is boolean` | `true`나 `false`일 때 | `true is boolean` → `true` |
| `x is list` | [[리스트]]일 때 | `[1,2] is list` → `true` |
| `x is dictionary` | [[딕셔너리]]일 때 | `[1,2] is dictionary` → `false` |
| `x is closure` | [[클로저]]일 때 | |

```stscript
/let bag ["검","방패"] |
/ife (bag is list) {: /echo 리스트다 :} |
/else {: /echo 리스트가 아니다 :}
```

`bag`에 리스트가 들어 있으므로 알림 `리스트다`가 뜹니다. `/let bag 검`처럼 글자를 넣었다면 `bag is list`가 `false`가 되어 `/else`의 알림 `리스트가 아니다`가 뜹니다.

### 리스트·딕셔너리 안 들여다보기: 점(`.`)

변수에 [[리스트]]나 [[딕셔너리]]가 들어 있으면 점을 찍어 안의 칸을 꺼냅니다.

```stscript
/let bag ["검", "방패", "포션"] |
/= bag.0 |
/echo
```

알림 `검`. 번호는 0부터 세므로 `bag.0`이 첫 번째 칸입니다.

| 식 | 결과 | 뜻 |
|---|---|---|
| `bag.0` | `검` | 0번(첫 번째) 칸 |
| `bag.-1` | `포션` | 음수는 뒤에서부터. `-1`은 마지막 칸 |
| `bag.length` | `3` | 칸 개수 |
| `bag.0.length` | `1` | 0번 칸에 든 글자(`검`)의 글자 수 |

딕셔너리는 점 뒤에 이름표를 씁니다.

```stscript
/let stat {"hp":100, "skills":["베기","막기"]} |
/= stat.hp |
/echo
```

알림 `100`. 점을 이어서 `stat.skills.0`이라고 쓰면 `skills` 리스트의 첫 칸 `베기`입니다.

리스트 안의 **모든** 항목에서 같은 칸을 한꺼번에 꺼낼 때는 `*.`을 씁니다.

```stscript
/let party [{"name":"가나디","hp":80}, {"name":"끼끼","hp":55}] |
/= party*.name |
/echo
```

알림 `["가나디","끼끼"]`. 항목마다 `name` 칸을 꺼내 새 리스트로 만든 것입니다. `party*.hp`는 `[80,55]`입니다.

### 정규식으로 비교 {#la-regex}

[[정규식]]은 글자를 "모양"으로 찾는 규칙입니다. 식에서는 글자가 어떤 모양에 맞는지 비교할 때 씁니다. 정규식은 슬래시 두 개 사이에 씁니다.

```stscript
/= '안녕하세요' == /하세요$/ |
/echo
```

알림 `true`. 정규식 `/하세요$/`의 `$`는 "글의 끝"을 뜻하는 기호라서, 이 식은 "`안녕하세요`가 `하세요`로 **끝나는가**"를 묻습니다.

자주 쓰는 정규식 기호입니다.

| 기호 | 뜻 | 예 |
|---|---|---|
| `^` | 글의 시작 | `/^안녕/` — `안녕`으로 시작 |
| `$` | 글의 끝 | `/하세요$/` — `하세요`로 끝남 |
| `.` | 아무 글자 하나 | `/가.다/` — `가나다`, `가마다` |
| `\d` | 숫자 하나 | `/\d\d/` — 숫자 두 개가 이어짐 |
| `+` | 바로 앞의 것이 하나 이상 | `/\d+/` — 숫자가 하나 이상 이어짐 |

닫는 슬래시 뒤에는 옵션 글자를 붙일 수 있습니다. 붙이지 않아도 됩니다. `i`는 "영어 대소문자를 가리지 않는다"는 옵션이라 `/hello/i`는 `Hello`, `HELLO`에도 맞습니다. 한글은 대소문자가 없으므로 위 예제에는 붙이지 않았습니다.

정규식 안에서 "또는"을 뜻하는 `|`는 명령 구분 기호와 겹치므로 `\|`로 씁니다: `/사과\|배/`(사과 또는 배). 글자 `|` 자체를 찾으려면 `\\\|`.

### 변수에 바로 넣기

식 맨 앞에 `변수 =`를 쓰면 계산 결과를 그 변수에 넣고, 넣은 값을 결과값으로도 남깁니다.

```stscript
/let x 2 |
/= x += 1 |
/echo x는 {{var::x}}
```

1. `/let x 2` — 범위 변수 `x`를 만들고 `2`를 넣습니다(`/let 이름 값`).
2. `/= x += 1` — 식 `x += 1`은 "`x`에 1을 더해서 다시 `x`에 넣어라"입니다. `x`는 `3`이 됩니다.
3. `{{var::x}}`가 `3`으로 바뀌어 알림 `x는 3`이 뜹니다.

| 식 | 뜻 |
|---|---|
| `x = 5` | `x`에 5를 넣음 |
| `x += 2` | 지금 값에 2를 더해서 넣음 |
| `x -= 2` | 지금 값에서 2를 빼서 넣음 |
| `x *= 2`, `x /= 2` | 곱해서, 나눠서 넣음 |
| `x //= 2`, `x %= 2`, `x **= 2` | 몫, 나머지, 거듭제곱을 넣음 |

- 같은 이름의 범위·채팅·전역 변수가 이미 있으면 그 변수를 바꿉니다. 없으면 새 범위 변수를 만듭니다.
- 리스트·딕셔너리의 한 칸에도 넣을 수 있습니다: `/= bag.0 = '낡은 검'`.

### 1 늘리기·줄이기

| 식 | 변수에 일어나는 일 | 결과값 |
|---|---|---|
| `++x` | 1 늘어남 | 늘어난 **뒤**의 값 |
| `--x` | 1 줄어듦 | 줄어든 뒤의 값 |
| `x++` | 1 늘어남 | 늘어나기 **전**의 값 |
| `x--` | 1 줄어듦 | 줄어들기 전의 값 |

`x`가 5일 때 `++x`의 결과값은 `6`, `x++`의 결과값은 `5`입니다. 어느 쪽이든 `x`는 6이 됩니다.

```stscript
/let y 0 |
/whilee (y++ < 3) {: /echo y는 {{var::y}} :}
```

`/whilee`는 식이 `true`인 동안 클로저를 되풀이하는 명령입니다(`/while`의 식 버전).

1. `/let y 0` — 범위 변수 `y`를 만들고 `0`을 넣습니다.
2. `/whilee`가 식 `y++ < 3`을 계산합니다. `y++`는 늘어나기 **전**의 값 `0`을 비교에 내놓고, 그 직후 `y`를 `1`로 늘립니다. `0 < 3`은 `true`이므로 클로저가 실행되어 알림 `y는 1`이 뜹니다.
3. 다시 식을 계산합니다. 비교에는 `1`이 쓰이고 `y`는 `2`가 됩니다. `1 < 3`은 `true`. 알림 `y는 2`.
4. 한 번 더. 비교에는 `2`가 쓰이고 `y`는 `3`이 됩니다. `2 < 3`은 `true`. 알림 `y는 3`.
5. 한 번 더. 비교에는 `3`이 쓰입니다. `3 < 3`은 `false`이므로 여기서 멈춥니다.

알림은 `y는 1`, `y는 2`, `y는 3` 세 번 뜹니다.

### 식에 값 넘겨주기

식 안에서는 변수 이름만 쓸 수 있고, `{{pipe}}` 같은 두 겹 매크로를 직접 쓰면 안 됩니다(위 "식에 쓰는 값" 참고). 그래서 앞 명령의 결과값 같은 것을 식에서 쓰려면, 식 명령에 `이름=값`을 붙여 **그 식에서만 쓰는 임시 변수**로 넘겨줍니다.

```stscript
/genraw foo와 bar 중 하나만 말해 |
/ife answer={{pipe}} ('foo' in answer) {: /echo foo라고 했다 :} |
/else {: /echo 다른 말을 했다 :}
```

1. `/genraw`가 AI에게 물어 답(예: `foo`)을 결과값으로 남깁니다.
2. `/ife` 뒤의 `answer={{pipe}}`가 그 답을 `answer`라는 이름의 임시 변수에 담습니다. 이 변수는 이 `/ife`의 식 안에서만 쓸 수 있고, 명령이 끝나면 사라집니다. 채팅 변수로 저장되지 않습니다.
3. 괄호 안의 `'foo' in answer`가 식입니다. 위 "비교"의 `in`으로, "`answer` 안에 `foo`라는 글자가 들어 있는가"를 묻습니다.
4. 들어 있으면 알림 `foo라고 했다`, 아니면 `/else`의 알림 `다른 말을 했다`가 뜹니다.

`/=`에도 같은 방식으로 넘깁니다: `/= x=5 y=3 x * y`의 결과값은 `15`입니다.
