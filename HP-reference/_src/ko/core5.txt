#0 실행할 도구 이름

@tools-register
AI가 대화 중에 스스로 부를 수 있는 **도구**를 새로 만듭니다. AI가 "이 도구를 써야겠다"고 판단해 부르면 넘겨준 [[클로저]]가 실행됩니다.
```stscript
/let key=echoSchema {"type":"object","properties":{"message":{"type":"string","description":"되풀이할 말"}},"required":["message"]} ||
/tools-register name=Echo description="사용자가 같은 말을 반복해 달라고 할 때 부른다" parameters={{var::echoSchema}} {: /echo {{var::arg.message}} :}
```
1. `echoSchema`에 "이 도구는 `message`라는 글자 하나를 받는다"는 정의를 넣습니다(JSON Schema라는 정해진 모양).
2. `Echo`라는 도구를 등록합니다. AI가 부르면 받은 `message`가 `{{var::arg.message}}`로 들어와 알림으로 뜹니다.
! 도구 사용(Function Calling)을 지원하는 [[Text Completion|Chat Completion]] API에서만 동작합니다. `description=`은 AI가 언제 부를지 판단하는 근거라 구체적으로 씁니다.
.name 도구 이름(AI에게 보이는 이름)
.description 도구가 하는 일. AI가 부를지 판단하는 근거
.parameters 받을 값의 정의. JSON Schema 모양의 딕셔너리
.displayName 화면에 보일 이름
.formatMessage 도구를 부른 기록을 채팅에 어떻게 보일지 정하는 클로저. 글자를 돌려줘야 함
.shouldRegister 답을 받을 때마다 이 도구를 쓸 수 있게 할지 정하는 클로저. `true`/`false`를 돌려줌
.stealth `true`면 도구 결과를 채팅에 보이지 않고, 결과를 받은 뒤 이어지는 답도 받지 않음

.uid 항목 번호

.system 맨 앞에 넣을 시스템 프롬프트
.length 최대 답 길이([[토큰]])
.generating 받는 동안의 창 제목
.completed 다 받은 뒤의 창 제목
.delay 다 받은 뒤 창이 저절로 닫히기까지의 시간(1000분의 1초 단위). `infinite`면 직접 닫을 때까지
=infinite 직접 닫을 때까지 남김
.stop 창에 중지 버튼을 보일지
.onStop 중지 버튼을 눌렀을 때 실행할 클로저
.onComplete 다 받은 뒤 실행할 클로저
#0 AI에게 보낼 글

@regex
정규식 [[확장]]에 만들어 둔 **찾아 바꾸기 스크립트**를 이름으로 골라 글에 적용하고, 바뀐 글을 결과로 남깁니다.
```stscript
/regex name=괄호지우기 (속마음) 안녕하세요 | /echo
```
`괄호지우기` 스크립트가 괄호 부분을 지우도록 만들어져 있다면 알림 `안녕하세요`.
! 그 스크립트가 켜져 있어야 합니다.
.name 쓸 정규식 스크립트 이름
#0 적용할 글

@regex-state
정규식 스크립트가 켜져 있으면 `true`, 꺼져 있으면 `false`를 결과로 남깁니다.
```stscript
/regex-state 괄호지우기 | /echo
```
#0 스크립트 이름

@regex-toggle
정규식 스크립트를 켜거나 끕니다. 바꾼 스크립트 이름을 결과로 남깁니다.
```stscript
/regex-toggle 괄호지우기
/regex-toggle state=off 괄호지우기
```
첫 줄은 켜져 있으면 끄고 꺼져 있으면 켭니다. 둘째 줄은 끕니다.
.state `on`(켜기), `off`(끄기), `toggle`(반대로, 기본)
.quiet 알림을 숨김
#0 스크립트 이름

@regex-preset
정규식 프리셋(스크립트 켜짐·꺼짐 상태를 묶어 저장한 것)을 고릅니다. 이름 없이 쓰면 지금 프리셋 ID를 결과로 남깁니다.
.quiet 알림을 숨김
#0 프리셋 이름 또는 ID
```stscript
/regex-preset 번역용
```
`번역용` 정규식 프리셋으로 바꿉니다.

@db
데이터 저장소(AI가 참고할 문서를 넣어 두는 곳) 창을 엽니다. 다른 이름 `/databank`, `/data-bank`.

@db-list
데이터 저장소에 넣어 둔 파일 목록을 결과로 남깁니다.
```stscript
/db-list source=chat field=name | /echo
```
지금 채팅에 넣어 둔 파일 이름 목록을 알림으로 띄웁니다.
.source 어느 범위의 파일인지
=global 모든 채팅 공통
=character 지금 캐릭터
=chat 지금 채팅
.field 무엇으로 목록을 만들지. `name`(파일 이름) 또는 `url`(주소, 기본)

@db-get
데이터 저장소 파일의 **글 내용**을 결과로 남깁니다.
```stscript
/db-get 설정집.txt | /echo
```
.source 찾을 범위: `global`, `character`, `chat`. 비우면 전부에서 찾음
#0 파일 이름 또는 주소(URL)

@db-add
데이터 저장소에 글을 **파일로 저장**하고, 그 주소를 결과로 남깁니다.
```stscript
/db-add source=chat name=요약.txt {{summary}}
```
지금 요약을 `요약.txt`로 이 채팅의 데이터 저장소에 넣습니다.
.source 저장할 범위: `global`, `character`, `chat`(기본)
.name 파일 이름. 비우면 자동
#0 파일 내용

@db-update
데이터 저장소 파일의 내용을 **바꿉니다**. 이름은 그대로이고 새 주소를 결과로 남깁니다. `name=`이나 `url=`로 어느 파일인지 고릅니다.
```stscript
/db-update source=chat name=요약.txt {{summary}}
```
.source 범위: `global`, `character`, `chat`(기본)
.name 바꿀 파일 이름
.url 바꿀 파일 주소
