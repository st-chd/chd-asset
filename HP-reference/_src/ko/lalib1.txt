@char-get
캐릭터 정보를 통째로([[딕셔너리]]) 또는 한 칸만 가져와 결과로 남깁니다.
```stscript
/char-get index=description 끼끼 | /echo
```
`끼끼`의 설명 칸을 알림으로 띄웁니다. 이름을 비우면 지금 캐릭터입니다.
! SillyTavern 기본 명령에도 같은 이름 `/char-get`이 있습니다. LALib가 켜져 있으면 `/char-get`은 이 LALib 쪽이 되고, 기본 명령은 다른 이름 `/char-data`로만 부를 수 있습니다. 둘은 쓰는 칸이 다릅니다(기본: `char=`, `field=` / LALib: `index=`, 이름 없는 인자).
.index 가져올 칸 이름(예: `description`, `personality`). 비우면 전체
#0 캐릭터 이름 또는 아바타 파일 이름. 비우면 지금 캐릭터

@test
두 값을 비교해 맞으면 `true`, 아니면 `false`를 결과로 남깁니다. `/if`에서 "비교"만 떼어 낸 명령입니다.
```stscript
/setvar key=hp 30 |
/test left=hp rule=lte right=50 | /echo
```
`hp`(30)가 50 이하이므로 알림 `true`.
! SillyTavern 기본 `/test`(정규식으로 글 찾기)를 대신합니다. LALib가 켜져 있는 동안에는 기본 `/test`를 쓸 수 없습니다.
.left 왼쪽 값. 숫자, 글자, 또는 변수 이름(그 값으로 비교)
.rule 비교 방법
.right 오른쪽 값. 숫자, 글자, 또는 변수 이름
=gt 왼쪽이 크다 `>`
=gte 크거나 같다 `≥`
=lt 왼쪽이 작다 `<`
=lte 작거나 같다 `≤`
=eq 같다
=neq 다르다
=not 왼쪽이 거짓이다(오른쪽은 무시)
=in 왼쪽 글 안에 오른쪽 글이 있다
=nin 왼쪽 글 안에 오른쪽 글이 없다

#0 도움말 주제

@=
**식**(계산식이나 비교식)을 계산해 결과로 남깁니다. 식 쓰는 법은 위 "LALib와 식" 설명에 있습니다.
```stscript
/= 1 + 2 * 3 | /echo
/= 'abc' == 'abc' | /echo
/= x=5 y=3 x * y | /echo
```
| 줄 | 결과 | 뜻 |
|---|---|---|
| 1 | `7` | 곱하기를 먼저 계산 |
| 2 | `true` | 글자는 작은따옴표로 |
| 3 | `15` | `x=5 y=3`으로 식에 값을 넘겨 줌 |
```stscript
/genraw 사과와 배 중 하나만 말해 |
/= answer={{pipe}} ('사과' in answer) | /echo
```
AI의 답에 `사과`가 들어 있으면 알림 `true`.
.expression variables 식 안에서 쓸 임시 값. `x=5`처럼 아무 이름으로 넘김
#0 계산할 식

@and
값이 **모두** `true`면 `true`, 하나라도 아니면 `false`를 결과로 남깁니다.
```stscript
/and true true true | /echo
/and true false true | /echo
```
첫 줄 `true`, 둘째 줄 `false`.
#0 검사할 값들(빈칸으로 여러 개)

@or
값 중 **하나라도** `true`면 `true`, 모두 아니면 `false`를 결과로 남깁니다.
```stscript
/or false true false | /echo
```
알림 `true`.
#0 검사할 값들(빈칸으로 여러 개)

@not
참과 거짓을 **뒤집어** 결과로 남깁니다. `false`면 `true`, 그 밖에는 `false`.
```stscript
/not false | /echo
```
알림 `true`.
#0 뒤집을 값

@pop
[[리스트]]의 **마지막 칸**을 꺼내 결과로 남깁니다. 변수 이름을 주면 그 변수에서도 그 칸이 빠집니다.
```stscript
/let bag ["검","방패","포션"] |
/pop bag | /echo 꺼낸 것: {{pipe}} |
/echo 남은 것: {{var::bag}}
```
알림 `꺼낸 것: 포션`, `남은 것: ["검","방패"]`.

@push
[[리스트]] **끝에** 값을 넣고, 바뀐 리스트를 결과로 남깁니다. 변수 이름을 주면 그 변수가 바뀝니다.
```stscript
/let bag ["검"] |
/push bag 방패 포션 |
/echo {{var::bag}}
```

#1 넣을 값들(빈칸으로 여러 개)

@shift
[[리스트]]의 **첫 칸**을 꺼내 결과로 남깁니다. 변수 이름을 주면 그 변수에서도 빠집니다.
```stscript
/let queue ["끼끼","가나디","도다리"] |
/shift queue | /echo 다음 차례: {{pipe}}
```
알림 `다음 차례: 끼끼`. `queue`에는 `["가나디","도다리"]`이 남습니다.
#0 리스트, 또는 리스트가 든 변수 이름

@unshift
[[리스트]] **맨 앞에** 값을 넣고, 바뀐 리스트를 결과로 남깁니다.
```stscript
/let queue ["가나디"] |
/unshift queue 끼끼 | /echo
```
알림 `["끼끼","가나디"]`.
#0 리스트, 또는 리스트가 든 변수 이름
#1 넣을 값들

@foreach
[[리스트]]나 [[딕셔너리]]의 **칸마다** 묶음을 한 번씩 실행합니다. 묶음 안에서 지금 칸의 값은 `{{var::item}}`, 번호(딕셔너리면 키)는 `{{var::index}}`입니다.
```stscript
/foreach ["가나디","끼끼","도다리"] {:
    /echo {{var::index}}번: {{var::item}} |
    /delay 400
:}
```
알림이 `0번: 가나디`, `1번: 끼끼`, `2번: 도다리`으로 차례로 뜹니다.
```stscript
/foreach {"hp":80,"mp":30} {: /echo {{var::index}} = {{var::item}} :}
```
딕셔너리는 `hp = 80`, `mp = 30`.
- 이름을 바꾸고 싶으면 묶음 맨 앞에 두 개를 적습니다: `{: who= n= /echo {{var::n}}: {{var::who}} :}`. 첫째가 값, 둘째가 번호입니다.
- `/break`로 중간에 끝낼 수 있습니다. 마지막으로 실행한 결과를 결과로 남깁니다.
#0 돌아볼 리스트 또는 딕셔너리
#1 칸마다 실행할 클로저

@map
[[리스트]]의 칸마다 묶음을 실행하고, 그 결과들을 모아 **새 리스트**로 만듭니다. 딕셔너리를 주면 같은 키의 딕셔너리로 만듭니다.
```stscript
/map [1,2,3] {: /mul {{var::item}} {{var::item}} :} | /echo
```
각 숫자를 제곱해 알림 `[1,4,9]`.
```stscript
/map ["가나디","끼끼"] {: /pass {{var::item}}님 :} | /echo
```
알림 `["가나디님","끼끼님"]`.
.aslist 딕셔너리를 넣었을 때도 결과를 리스트로
#0 돌아볼 리스트 또는 딕셔너리
#1 칸마다 실행할 클로저. 그 결과가 새 칸의 값이 됨

@whilee
조건이 맞는 **동안** 묶음을 반복합니다. 조건은 LALib 식(괄호 안에 쓴 계산식) 또는 클로저로 씁니다. 매번 반복하기 **전에** 조건을 봅니다.
```stscript
/let i 0 |
/whilee (i < 3) {:
    /= i += 1 |
    /echo {{var::i}}번째
:}
```
알림이 `1번째`, `2번째`, `3번째`로 뜨고 멈춥니다.
! 기본 `/while`과 달리 **반복 횟수 제한이 없습니다**. 조건이 영원히 맞으면 끝나지 않으니, 반드시 언젠가 조건이 틀리게 만드세요. `/break`로도 빠져나올 수 있습니다.
.expression variables 식 안에서 쓸 임시 값
#0 조건. 괄호로 감싼 식(예: `(i < 3)`) 또는 `true`/`false`를 돌려주는 클로저
#1 반복할 클로저

@reduce
[[리스트]]의 칸들을 차례로 묶음에 넣어 **하나의 값으로 합칩니다**. 묶음은 "지금까지 합친 값"과 "이번 칸"을 받아 새로 합친 값을 돌려줍니다.
```stscript
/reduce [1,2,3] {: acc= cur= /= acc + cur :} | /echo
```
1. 처음에는 첫 칸 `1`이 합친 값(`acc`)이고, 둘째 칸 `2`부터 시작합니다: 1 + 2 = 3
2. 3 + 3 = 6
3. 알림 `6`.
```stscript
/reduce initial=10 [1,2,3] {: acc= cur= /= acc + cur :} | /echo
```
`initial=10`이 처음 값이라 10 + 1 + 2 + 3 = 알림 `16`.
- 묶음 맨 앞의 이름은 순서대로 "합친 값", "이번 칸", "이번 번호"입니다(최대 3개).
.initial 합친 값의 처음 값. 비우면 첫 칸
#0 합칠 리스트
#1 합치는 방법(클로저). 돌려준 값이 다음 "합친 값"이 됨

@groupby
[[리스트]]의 칸들을 **기준값이 같은 것끼리 묶어** [[딕셔너리]]로 만듭니다. 결과는 `{"기준값":[칸들…]}` 모양입니다.
```stscript
/let party [{"name":"가나디","job":"전사"},{"name":"끼끼","job":"마법사"},{"name":"도다리","job":"전사"}] |
/groupby {{var::party}} item.job | /echo
```
직업(`job`)으로 묶어 알림 `{"전사":[가나디·도다리의 칸],"마법사":[끼끼의 칸]}`.
기준 자리의 `item`은 지금 칸을 뜻합니다. `item`만 쓰면 값 자체로 묶습니다: `/groupby ["a","a","b"] item` → `{"a":["a","a"],"b":["b"]}`.
#0 묶을 리스트
#1 기준. `item.칸이름` 같은 식, 또는 기준값을 돌려주는 클로저

@sorte
[[리스트]]를 **정렬**합니다. 리스트 대신 **변수 이름**을 주면 그 변수 자체가 정렬됩니다.
```stscript
/sorte [5,3,-10,0] | /echo
/sorte [5,3,-10,0] (b <=> a) | /echo
```
첫 줄은 작은 순서 `[-10,0,3,5]`, 둘째 줄은 큰 순서 `[5,3,0,-10]`.
```stscript
/let party [{"name":"가나디","hp":80},{"name":"끼끼","hp":55}] |
/sorte party (a.hp <=> b.hp) |
/echo {{var::party}}
```
`hp`가 작은 순서로 `party` 변수 자체가 정렬됩니다(끼끼, 가나디).
- 비교 자리에는 두 칸 `a`, `b`를 비교해 "a가 앞이면 음수, 같으면 0, b가 앞이면 양수"가 되는 식을 씁니다. `<=>`가 바로 그런 값(-1/0/1)을 냅니다.
- `{{var::party}}`처럼 값을 넘기면 정렬된 결과만 남고 원래 변수는 그대로입니다.
! 비교를 클로저로 쓰면 긴 리스트에서 매우 느립니다.
.key 각 칸에서 정렬 기준을 뽑는 클로저(딕셔너리 칸의 특정 값으로 정렬할 때)
#0 정렬할 리스트, 또는 리스트가 든 변수 이름
#1 비교 방법. 비우면 `(a <=> b)`(작은 순서). `(b <=> a)`면 큰 순서

@flatten
리스트 안에 리스트가 든 것을 **한 겹으로 펼칩니다**.
```stscript
/flatten [1, [2, 3], [4, [5]]] | /echo
/flatten depth=0 [1, [2, 3], [4, [5]]] | /echo
```
첫 줄은 한 겹만 펼쳐 `[1,2,3,4,[5]]`, 둘째 줄은 끝까지 펼쳐 `[1,2,3,4,5]`.
.depth 몇 겹까지 펼칠지. 기본 1, `0`이면 끝까지
#0 펼칠 리스트

@filter
[[리스트]]나 [[딕셔너리]]에서 조건에 **맞는 칸만 남깁니다**.
```stscript
/filter [1,2,3,4,5] (item > 2) | /echo
```
2보다 큰 것만 남아 알림 `[3,4,5]`.
```stscript
/filter ["사과","바나나","배"] ('나' in item) | /echo
```
`나`가 들어간 것만 남아 알림 `["바나나"]`.
조건에서 `item`은 지금 칸의 값, `index`는 번호(키)입니다. 클로저로 써도 됩니다: `{: /test left={{var::item}} rule=gt right=2 :}`.
#0 거를 리스트 또는 딕셔너리
#1 조건. 괄호 식 또는 `true`/`false`를 돌려주는 클로저

@find
조건에 맞는 **첫 칸**을 찾아 결과로 남깁니다. 없으면 빈 값입니다.
```stscript
/find [1,2,3,4,5] (item > 2) | /echo
/find index=true [1,2,3,4,5] (item > 2) | /echo
```
첫 줄은 알림 `3`(값), 둘째 줄은 알림 `2`(그 칸의 번호).
.index `true`면 값 대신 그 칸의 번호(키)를 돌려줌
.last `true`면 처음이 아니라 **마지막**으로 맞는 칸을 찾음
#0 찾을 리스트 또는 딕셔너리
#1 조건. 괄호 식 또는 클로저

@slice
리스트나 글의 **일부분**을 잘라 결과로 남깁니다. 번호는 0부터, 음수는 뒤에서부터입니다.
```stscript
/slice start=2 length=3 [10,20,30,40,50,60] | /echo
/slice start=-3 안녕하세요 | /echo
```
첫 줄은 2번부터 3개로 알림 `[30,40,50]`, 둘째 줄은 뒤에서 3글자 `하세요`.
.start 시작 위치(이 칸 포함). 음수는 뒤에서
.end 끝 위치(이 칸 앞까지). `length=`와 둘 중 하나만
.length 몇 개를 자를지
#0 자를 리스트 또는 글

@splice
리스트의 정한 자리에서 칸을 **지우거나 끼워 넣은 새 리스트**를 결과로 남깁니다. 원래 리스트는 그대로입니다.
```stscript
/splice start=1 delete=1 ["검","방패","포션"] | /echo
/splice start=1 insert=활 ["검","방패","포션"] | /echo
```
첫 줄은 1번 칸을 지워 `["검","포션"]`, 둘째 줄은 1번 자리에 끼워 `["검","활","방패","포션"]`.
.start 작업할 자리(0부터). 음수는 뒤에서
.delete `start`부터 지울 개수. 값 없이 `delete=`만 쓰면 끝까지 모두 지움
.insert `start` 자리에 넣을 값. 리스트를 주면 그 칸들을 펼쳐서 넣음

```stscript
/shuffle ["가나디","끼끼","도다리"] | /echo
```
알림 `["도다리","가나디","끼끼"]`처럼 매번 다른 순서.
#0 섞을 리스트

@pick
리스트에서 **무작위로** 하나(또는 여러 개)를 뽑아 결과로 남깁니다. 여러 개를 뽑을 때 같은 칸이 두 번 나오지 않습니다.
```stscript
/pick ["맑음","흐림","비"] | /echo
/pick items=2 ["가나디","끼끼","도다리"] | /echo
```
첫 줄은 셋 중 하나, 둘째 줄은 두 명을 뽑아 `["끼끼","가나디"]` 같은 리스트.
! 매크로 `{{pick}}`(한 번 뽑으면 고정)과 다른 명령입니다. 이 명령은 실행할 때마다 새로 뽑습니다.
.items 뽑을 개수. 2 이상이면 리스트로 돌려줌
.list `true`면 하나만 뽑아도 리스트(`["비"]`)로

@split
글을 정한 글자가 나올 때마다 **잘라** 리스트로 만듭니다. 기본은 쉼표(`,`)로 자릅니다.
```stscript
/split 사과, 배, 귤 | /echo
/split find=" " 오늘 날씨 좋다 | /echo
```
첫 줄은 알림 `["사과","배","귤"]`(조각 앞뒤 빈칸은 자동으로 지움), 둘째 줄은 빈칸으로 잘라 `["오늘","날씨","좋다"]`.
[[정규식]]도 됩니다: `find="/\s+/"`(빈칸이 몇 개든 한 번에).
.find 자를 기준 글자 또는 정규식. 기본 `,`
.trim 조각마다 앞뒤 빈칸을 지울지. 기본 `true`
