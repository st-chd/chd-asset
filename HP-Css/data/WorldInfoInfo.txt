[카테고리] UI
[확장프로그램] 월드인포인포
[제목] 플로팅 아이콘 꾸미기
[태그] WorldInfoInfo, 버튼, 아이콘, 꾸미기
[CSS코드]
/* 그림자 없애기 */
.stwii--trigger, .stwii--panel { filter: none !important; }

/* 아이콘 바꾸기 */
.stwii--trigger.fa-solid::before { content: '\f075'; }

/* 알림 뱃지 위치, 색 바꾸기 */
.stwii--trigger:not([data-stwii--badge-count="0"])::after {
top: 25%; left:30%;
background: transparent !important;
color: var(--SmartThemeBodyColor) !important;}
[/CSS코드]
[팁] `\f075`는 자유롭게 수정하세요. SVG도 가능합니다.
알림 뱃지 색상만 바꾸고 싶을 땐 [[플로팅 아이콘 알림 뱃지 색상 바꾸기]] 혹은 [[플로팅 아이콘 알림 뱃지 색상 진하게 바꾸기]]를 확인하세요.

알림 색상을 진하게 바꾸고 싶다면 [[플로팅 아이콘 알림 뱃지 색상 진하게 바꾸기]]를 확인하세요.
