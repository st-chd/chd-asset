1. 어시봇 채팅(혹은 저장용으로 쓸 채팅)을 열고,
2. `/send` 입력 후 `마법봉` - `파일 첨부하기`로 이미지를 보냅니다. (깔끔하게 이미지만 보내기 위해서입니다. 텍스트 입력해서 보내도 상관 없어요.)
3. 채팅창에서 보내진 이미지를 눌러 `다른 이미지로 저장`을 누르면 `1231231231231_12312312312312312.png` 형식으로 파일명, 확장자가 뜹니다.
4. 텍스트를 전부 복사해서 경로에 `/user/images/Assistant/1231231231231_12312312312312312.png` 를 입력 하면 됩니다.

- 이미지를 보내 놓은 **채팅방**과 이미지가 있는 **채팅**을 삭제하면 안 됩니다.
- 어시봇이 아니라 다른 캐릭터여도 상관 없습니다. 다른 캐릭터일 경우 `/Assistant/` 부분을 캐릭터 이름으로 바꿔주세요.

SillyTavern 안에 있는 config.yaml 파일을 수정하고 썸네일 폴더를 삭제 후 재부팅 합니다.
`❗❗ 주의: default 폴더 안에 있는 config.yaml 파일이 아닙니다. ❗❗`
`썸네일 폴더를 전부 삭제하면 로딩이 오래 걸립니다.`

📱 모바일(터먹스 등):
1. cd SillyTavern
2. nano config.yaml
3. 아래로 쭉 내려서 thumbnails 내용 수정
4. Ctrl+X 누르고 Y 누르고 엔터
5. rm -rf data/default-user/thumbnails/*
6. 실리 재시작

💻 컴퓨터:
1. 실리 폴더 - config.yaml 파일 열고 내용 똑같이 수정
2. data - default-user - thumbnails 폴더 안에 있는 폴더(avatar, bg, persona) 전부 삭제
3. 실리 재시작

* 폰트 아이콘 형식이 아닌데 새로 지정하는 거라면 font-family: 'Font Awesome 6 Pro', 'Font Awesome 6 Free', 'Font Awesome 5 Free'; 를 추가로 넣어줘야 함
