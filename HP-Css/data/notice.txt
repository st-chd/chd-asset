# ============================================================
# 이 파일은 개별 CSS 카드가 아니라, 페이지 상단에 항상 뜨는
# "공지 배너"에 그대로 표시됩니다.
#
# - "#"으로 시작하는 줄은 주석이며 화면에 표시되지 않습니다.
# - 줄바꿈은 그대로 유지되어 보여집니다.
# - 파일을 비우거나 삭제하면 배너 자체가 사라집니다.
# - 내용이 길면 자동으로 "더 보기" 버튼이 생깁니다.
# - {{표시할 텍스트|이미지URL}} 형식으로 쓰면, 그 텍스트에 마우스를 올렸을 때
#   (또는 키보드로 포커스했을 때) 이미지가 롤오버 팝업으로 뜹니다.
#   예: 맨 아래 {{Custom CSS 칸|images/custom-css-location.png}}에 붙여넣고
#   이미지URL은 절대경로(https://...)든 이 사이트 안의 상대경로(images/xxx.png)든 상관없습니다.
#
# 예시: 테스트 환경 안내, CSS 적용 위치, 안 될 때 대처법,
#       출처 관련 안내 등 CSS와 직접 상관없는 전체 공지사항을
#       여기에 적으면 됩니다.
# ============================================================

1. CSS 적용 방법: 사용자 설정 → 맨 아래 {{사용자 정의 CSS|img/css_position.png}}에 넣으세요.
2. 내용 중에는 달글 확장CSS도 있습니다. 불편하다면 꼭 얘기 해 주세요. 바로 내리겠습니다.
3. 제가 테스트한 환경은 [컴: 엣지]와 [폰:갤럭시]입니다. 다른 환경에서는 다르게 보이거나 일부 적용이 안 될 수 있습니다.(제보 환영)
4. 적용이 안 될 때는 이미 다른 CSS와 선택자가 겹치고 있을 확률이 높습니다. 중복 CSS를 제거하거나, 해당 속성 뒤에 !important를 붙여보세요.
5. 제가 쓰는 방법이 정확한 게 아니기 때문에 더 좋은 방법이 있거나 잘못된 코드가 있다면 알려주세요.
6. 쓸데없는 것도 많고(제가원래사소한거에집착이심함) 본달에서 주운 것도 많습니다(감사합니다)
