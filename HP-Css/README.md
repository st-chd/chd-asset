# SillyTavern CSS 보관함

SillyTavern 및 확장 프로그램용 CSS 코드를 검색·분류·복사할 수 있는 정적 웹사이트입니다.
빌드 과정 없이 순수 HTML/CSS/JS로 동작하며, `data/` 폴더의 `.txt` 파일에 정해진 형식으로
텍스트만 추가하면 새 CSS가 사이트에 자동으로 반영됩니다.

## 폴더 구조

```
css-hub/
├── index.html
├── netlify.toml
├── css/
│   └── style.css
├── js/
│   └── app.js
└── data/
    ├── manifest.txt     ← 불러올 .txt 파일 목록 (파일명만 한 줄씩)
    ├── chat.txt         ← 카테고리/용도별로 자유롭게 나눈 CSS 파일들
    ├── font.txt
    ├── background.txt
    ├── gallery.txt
    ├── timeline.txt
    └── ui.txt
```

데이터가 파일 하나에 몰리지 않도록, `data/` 폴더 안에 여러 개의 `.txt` 파일로 나눠서 관리합니다.
어떻게 나누든 상관없습니다 (카테고리 1개당 파일 1개로 맞출 필요도 없음) — `manifest.txt`에
등록된 파일들을 전부 불러와서 하나로 합친 뒤 화면에 뿌려주는 방식입니다.

## 기존 파일에 CSS 추가하는 법

`data/` 안의 아무 `.txt` 파일(예: `chat.txt`) 맨 아래에 아래 형식을 그대로 복사해서
붙여넣고 내용만 바꾸세요. 각 항목 사이는 반드시 `===`만 있는 줄로 구분합니다.

```
[카테고리] 채팅창
[확장프로그램] SillyTavern
[제목] 다크 블루 채팅 말풍선
[태그] 다크모드, 블루, 말풍선
[CSS코드]
.mes {
  background: #10192e;
}
[/CSS코드]
[미리보기] https://예시.com/preview.png
[팁] 사용 방법이나 주의사항을 적어주세요.
===
```

| 필드 | 필수 여부 | 설명 |
|---|---|---|
| `[카테고리]` | 필수 | 사이드바 분류 기준 (채팅창, 폰트, 배경, UI 등 자유롭게) |
| `[확장프로그램]` | 필수 | SillyTavern 본체면 `SillyTavern`, 확장 프로그램이면 그 이름 |
| `[제목]` | 권장 | 카드에 표시될 이름. 생략하면 "제목 없음"으로 표시 |
| `[태그]` | 선택 | 쉼표로 구분, 검색에 사용됨 |
| `[환경]` | 선택 | `컴퓨터`, `모바일` 중 해당하는 것을 쉼표로. 카드에 💻/📱 라벨이 붙고, 사이드바 "환경" 칩으로 필터링됨. 생략하면 컴퓨터/모바일 모두에 해당하는 것으로 처리됨 |
| `[CSS코드]` ~ `[/CSS코드]` | 필수 | 여는 태그와 닫는 태그 사이에 실제 CSS 작성 |
| `[미리보기]` | 선택 | 이미지 URL. 카드를 클릭했을 때 모달에 표시됨 |
| `[팁]` | 선택 | 사용법, 주의사항 등 자유 텍스트 (여러 줄 가능, 아래 "팁 서식" 참고) |

- `#`으로 시작하는 줄은 주석으로 처리되어 무시됩니다.
- 필수 필드(`카테고리`, `확장프로그램`, `CSS코드`)가 없는 항목은 자동으로 건너뜁니다.
- 순서는 자유입니다. 위 예시 순서를 그대로 따를 필요는 없습니다.

### `[환경]` 예시

```
[카테고리] UI
[확장프로그램] 기본
[제목] 모바일 하단 여백 줄이기
[환경] 모바일
[CSS코드]
#send_form { padding-bottom: 4px !important; }
[/CSS코드]
===
```

`컴퓨터, 모바일`처럼 둘 다 적어도 되고, 필드 자체를 생략하면 두 환경 모두에 해당하는
항목으로 취급되어 어떤 환경 필터에서도 보입니다.

### 팁 서식 (`[팁]` 안에서 쓸 수 있는 표시)

`[팁]` 필드 안에서는 아래 세 가지를 쓸 수 있고, 모달 창에서 그대로 렌더링됩니다.
(카드 목록의 짧은 미리보기에는 적용되지 않고, 모달을 열었을 때만 적용됩니다.)

| 문법 | 결과 |
|---|---|
| `` `코드` `` | `코드`처럼 인라인 코드 스타일로 표시 |
| `**굵게**` | **굵게** 강조 표시 |
| `[[다른 항목의 정확한 제목]]` | 클릭하면 그 제목을 가진 항목의 모달이 바로 열림 |

`[[ ]]` 안의 텍스트는 연결하려는 항목의 `[제목]` 값과 정확히 (띄어쓰기까지) 같아야
연결됩니다. 예:

```
[팁] 위 [[인풋창 퀵 페르소나 크기 축소]]와 같이 쓰면 비율이 맞아요.
`#quickPersona`의 값을 함께 조절하세요.
```



## 새 카테고리(파일)를 추가하는 법

파일이 너무 길어졌거나, 새로운 묶음(예: 새 확장 프로그램)이 생겼다면 파일을 새로 만드세요.

1. `data/` 폴더 안에 새 `.txt` 파일을 만듭니다. (예: `data/theme.txt`)
2. 위와 동일한 형식으로 항목을 작성합니다.
3. `data/manifest.txt`에 파일명을 한 줄 추가합니다.

   ```
   chat.txt
   font.txt
   background.txt
   gallery.txt
   timeline.txt
   ui.txt
   theme.txt   ← 새로 추가
   ```

4. GitHub에 push하면 Netlify가 자동으로 다시 배포하고, 사이트는 `manifest.txt`에
   적힌 파일들을 모두 불러와 합쳐서 보여줍니다.

> `manifest.txt`에 등록되지 않은 `.txt` 파일은 화면에 반영되지 않습니다. 반대로,
> `manifest.txt`에 파일명은 있는데 실제 파일이 없거나 이름이 다르면 화면 상단에
> 어떤 파일을 못 불러왔는지 경고 메시지가 표시됩니다.

## CSS 없이 순수한 팁만 올리고 싶을 때

"파일 링크는 이렇게 복사해라", "이 파일을 열어서 이 부분을 고쳐라" 같이
CSS 코드 자체는 없는 팁도 카드 형태로 올릴 수 있습니다. `[CSS코드]` ~ `[/CSS코드]`
부분을 통째로 생략하면 됩니다.

```
[카테고리] 팁
[확장프로그램] 공통
[제목] 파일 링크는 이렇게 복사하세요
[태그] 링크, 공유
[팁]
디스코드나 카페에 파일을 올릴 때는 재업로드해서 새 링크를 공유해주세요.
원본 링크를 그대로 돌리면 나중에 만료될 수 있습니다.
===
```

- CSS가 없으면 카드에 "가이드" 배지가 붙고, 코드 박스 대신 팁 내용이 미리보기로 표시됩니다.
- 모달을 열었을 때도 CSS 코드 카드와 구분되도록, 어두운 코드 박스가 아니라 밝은 "가이드" 스타일로 표시됩니다.
- `[확장프로그램]`은 필수 필드라서 생략할 수 없는데, 특정 확장 프로그램에 국한되지 않는
  일반 팁이라면 `공통`처럼 편한 이름을 값으로 넣어서 쓰면 됩니다. (필터 칩에 "공통"이 하나 더 생길 뿐,
  동작에는 문제 없습니다.)
- 검색·카테고리·필터·복사 기능이 CSS 카드와 완전히 동일하게 적용됩니다. (복사 버튼을 누르면
  팁 텍스트가 복사됩니다.)
- 예시가 `data/tips.txt`에 들어있으니 참고해서 이어 쓰면 됩니다.

## 사이트 전체 공지사항 (Daum 카페의 "안내문" 같은 것)

"제가 테스트한 환경은 엣지/갤럭시입니다", "CSS는 여기에 붙여넣으세요",
"안 되면 !important를 붙여보세요", "문제 되면 내리겠습니다" 같이 특정 CSS 하나에 딸린 게
아니라 **사이트 전체에 걸리는 안내문**은 카드로 넣지 않고, `data/notice.txt` 파일에 적습니다.

- 이 파일 내용은 검색창 바로 아래, 페이지 맨 위에 배너 형태로 항상 노출됩니다.
- 줄바꿈은 그대로 유지되어 보여지고, `#`으로 시작하는 줄은 주석 처리됩니다.
- 내용이 길면 자동으로 "더 보기 / 접기" 버튼이 생겨서 카드 목록을 가리지 않습니다.
- 파일을 비우거나 지우면 배너 자체가 사라집니다.
- `{{표시할 텍스트|이미지URL}}` 형식으로 쓰면 해당 텍스트에 마우스를 올렸을 때(또는 키보드
  포커스 시) 이미지가 롤오버 팝업으로 뜹니다. 예: `맨 아래 {{Custom CSS 칸|images/custom-css-location.png}}에`
  이미지URL은 외부 링크(`https://...`)도 되고, 저장소 안에 이미지를 넣어두고
  `images/파일명.png` 같은 상대경로로 써도 됩니다.
- 예시가 이미 `data/notice.txt`에 들어있으니, 실제 안내 문구로 내용만 바꿔서 쓰면 됩니다.

정리하면:
| 넣고 싶은 내용 | 넣을 곳 |
|---|---|
| 특정 CSS 코드 + 그 코드에 대한 팁 | 해당 카테고리 `.txt` 파일의 `[팁]` 필드 |
| CSS와 무관한 개별 팁 (링크 복사법, 특정 파일 수정법 등) | `[CSS코드]`를 생략한 카드 (`data/tips.txt` 등) |
| 사이트 전체 공지/디스클레이머 (테스트 환경, 출처 안내 등) | `data/notice.txt` (상단 배너) |
